## Smallest fresh-operation composition

The before build_current_scene called verified_animation, which already calls
animation_inputs and verifies its complete native output/supporting artifacts,
parents, currentness, replay and fencing. It then called animation_inputs again
immediately to reconstruct the same rows. This repetition is demonstrated by the
actual source call graph. An attempted Windows actual-upstream profiling probe
failed before Scene IR at Director's expired-lease fence; it produced no Scene IR
runtime call-count/performance proof. Linux after evidence remains mandatory.

Task036 now captures precisely the bundle consumed by one unchanged native
Animation verification, within a ContextVar scope for that service/run/tenant.
Publication or missing sync references reject before native input access.
Exactly one captured bundle is required. It is returned only after full native
verification succeeds; exceptions propagate and the token always restores.
Every build and subsequent call performs fresh native verification. There is no
cross-call, ACK, publication, revision, authorization or store cache. All Scene IR
scope/catalog/adoption/conservation/codec/native validation/loader checks remain.
This removes redundant work, not a validation gate. It is not asserted to explain
every historical signal-9 failure or to guarantee production performance.
