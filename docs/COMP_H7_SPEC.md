## Environment, trust, resources
Linux runtime needs Python/Matplotlib/FreeType, seccomp library, Fontconfig, FFmpeg/ffprobe, Node and the exact generated npm pins. User/mount/PID/network namespaces must be permitted; private procfs is mandatory for the strict browser worker. Unsupported kernel policy fails closed, with no downgrade. Package identity validates bytes/lock agreement, not upstream publisher signatures. Process limits and private tmpfs are not aggregate cgroups.

No API key, browser download or npm package is implicitly fetched. No font files are distributed. Real-source measurement helpers are separately hashed and do not rewrite original Scene.tsx. Instrumentation adds a nonpainting observer, waits font readiness and frames; its actual pinned execution remains unverified.

Test doubles and synthetic npm directories exist only in explicitly labelled tests/diagnostic harnesses. Production witness validation requires an in-process seal minted by the producer that executed the real child. This is not protection against an already-compromised Python interpreter; the service/operator remains in the trust boundary.
