# Traceability and evidence checklist

Recovered binding requirements: continuation rather than restart; bounded task
specs, source lineage, exact interfaces, implementation, adversarial tests, real
native execution where possible, fresh extraction, preservation, task/integrated
ZIPs, master backup, manifest/checksums, gap ledger and continuation. These are
implemented here. The full original-chat twenty-step wording is not claimed to
have been recovered verbatim from the H3 archive.

The specs identify each task and the documented H4 capability it replaces. Actual
test JSON/logs record execution on selected source hashes. Fresh archive checks
are reported separately from prepackage tests. Atomic test repetitions are
subsets of the new regression, not extra unique tests. The native benchmark uses
synthetic text, ephemeral authority and current actual system tools, with those
limits stated. No missing external acceptance gate is converted into a pass.
