# ADR DIR CONTEXT 011 — optional source-bound context on the existing PED boundary

Status: implemented in staged DIR batch 011; canonical integration pending DIR
scope completion and re-audit. Recorded 2026-09-14. Canonical base:
`bc3147db408fc5a5d54017c8b907f580477ff2c3`.

The recovered design requires prerequisite-aware teaching, uncertainty-aware
adaptation, source-preserving mathematical explanation and shared learning
structures for video and games. Batch 010 has the functioning registered DIR,
annotation, recovery and consumer boundary, but no typed rich context binding.

We add a versioned `pedagogy.teaching_context` artifact as an optional parent of
the existing PED plan. DIRECTOR keeps its existing two stage inputs and its
source/RE/PED parent tuple. Known source-bound context records call original
canonical KI/PR/MATH/PED functions and recompute results on load. Selected
cross-lesson bridge decisions reuse original PED objectives and assessments;
they never invent mastery, curriculum or a new questionnaire.

Context-aware model outputs use two explicitly known frozen subclasses, with
required host-defined teaching obligation IDs and actual narrated span bindings.
Context-free record schemas/serialization remain unchanged. Full fingerprints,
revalidation and ancestry feed the existing phase-repair/currentness mechanism.
Source expressions, conditions, uncertainty and original archives are retained.

This choice avoids replacing the stage graph or weakening the existing input,
replay and acceptance contracts. A new orchestration path or broad untyped
context dictionary would create a second source of authority. Assuming that an
earlier lesson was mastered would silently remove prerequisite obligations.

Tradeoffs: context extraction/scoring are supplied upstream; a bounded algebra
adapter is not a universal math codec and numerical probes are not proof.
Cross-lesson scopes can grow until resource budgets fail; segmentation remains
implementation work. Reported mastery changes prioritization but cannot waive
prerequisites. Lexical realization bindings need factual and semantic review.
Code changes conservatively invalidate old generation-reuse eligibility.

Evidence: CONTEXT_CONTRACTS.md, the new context/teaching/integration tests,
contextual_director_walkthrough.py and preservation/atomic ZIP verification.
All output remains unaccepted. Canonical integration must place this decision
under `docs/adr/` while preserving the original staged artifact and history.
