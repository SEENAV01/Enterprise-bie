# ADR DIR 012 — windows over existing teaching decisions

Status: implemented and tested for the bounded scope in WINDOW_CONTRACTS.md.
Original DIR completion remains 37/37; broader DIR implementation and BIE
acceptance remain open. Canonical baseline remains

## Problem

Batch 011 supplied source-bound KI/PR/math/mastery context and explicit teaching
obligations to the existing director. A single generation request still carried
all selected source pages and teaching data. Larger valid inputs exceeded the
request limit before transport. Original source conditions, prerequisite context,
math steps and product requirements must survive any execution decomposition.

## Decision

Add an explicit policy subclass and a window branch to the existing executor's
generation function. Group complete actual PED decisions in dependency order.
Preserve complete cited pages, supporting prerequisite records and the relevant
RE closure. Retain whole supplied math chains. Input projections have a separate
type and cannot be presented as verified upstream artifacts.

First obtain every window plan, assemble the original global IR and run the
existing full-scope validators. Then generate each scene against its window,
global plan fingerprint, complete objective/dependency outline, completed ledger
and exact recent narration. Store every generated scene without truncation and
compile through the original narration, factual, timing and game-handoff path.
The prompt asks for grounded continuity; validators establish structural/source
coverage. Live semantic quality requires independent evaluation.

Share the original request-material recipe for both transport and replay
verification. Persist known window result types and reconstruct requests on
annotation, repair and consumer revalidation. Extend four existing source files
with before/after provenance: director_model.py, grounded_directing.py,
recovery_codec.py and narration_annotations.py. Add context_windows.py and
windowed_directing.py. Existing source identities, default schemas, original
executor/revision/consumer modules, original archives and tests remain intact.

## Consequences and boundaries

Larger selected lessons can execute when complete atomic contexts and later
continuity/plan payloads fit. A window's local success is insufficient for global
lesson success. Resource overruns and missing prerequisites fail explicitly;
window count is a resource budget, not a teaching-duration cap. The supplied
fixtures allow different scene counts for one decision.

The global ledger and recent exact speech provide bounded continuity context;
they do not provide full earlier wording or prove learner understanding. The
unmodified full-script annotation/reviewer phase can still overflow, as can the
factual critic's indivisible complete-page scope. Those boundaries are covered
by negative tests and retained in the capability audit. This is not universal
book-length execution. Broad context retrieval/discourse reconciliation,
scene-local repair and production catalog recovery remain future implementation.

No new UI flow, mandatory questionnaire, universal scene template, arbitrary
duration target, alternate product pipeline or substitute for playable revision
games is introduced. The original source-to-structured-IR and compiler/runtime
architecture remains the authority.
