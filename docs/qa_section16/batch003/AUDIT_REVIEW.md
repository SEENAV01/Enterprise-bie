## Limits deliberately not hidden

Factual evaluation operates on reviewed normalized propositions. Normalization,
reference validity, broad linguistic consistency and teaching-depth adequacy need
real providers and calibration. These remain open, not relabeled as complete merely
because HMAC checks succeed. Context/cardinality rules are explicit and conservative;
unsupported logic is reviewed rather than guessed. Multi-valued alternatives and
reference uncertainty are not collapsed. Duplicate links/votes cannot inflate
coverage or quorum. Critical concept gaps cannot disappear inside averages.

The release bridge intentionally refuses semantic_correctness PASS even for the
positive text-only control, because actual video/game semantic fidelity has not
been checked. Existing source gates are recomputed from real bytes. Adapters
preserve canonical review flags but do not migrate the live operator/worker path.

No live provider, real-book, media/game runtime or full repository validation has
been performed. Section15 is externally owned, not waiting for this batch and not
changed here. Production credentials, immutable publication storage, platform
matrix, resource/performance acceptance and full-section hardening remain open.
