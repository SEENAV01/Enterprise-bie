# Legacy GAME DSL Compatibility

Canonical repository baseline at Batch 01 start contains the older `BIE_GAME_DSL_001` contract. Batch 01 v2 treats that format as read-only legacy.

Automatic migration is intentionally fail-closed because v1 does not encode all v2 requirements such as strict hashed provenance, typed expression AST, semantic visual hierarchy, pedagogical motion/camera intent, accessible action equivalence and the anti-slide experience-quality contract. A later migration may only proceed with explicit enrichment evidence; it must not fabricate missing semantics.
