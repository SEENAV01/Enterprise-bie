# Studio-Quality / Anti-Slide Contract

Batch 01 encodes these non-negotiable intents into the GAME IR itself:

1. Core learning experiences may not be slide/reference-only.
2. MCQ-only core gameplay is forbidden by quality intent.
3. Stateful interaction is required by default.
4. Semantic visual entities are required.
5. Dynamic manipulation/simulation/prediction/causal experiences require pedagogically purposeful motion.
6. Camera movement may exist only with explicit pedagogical purpose and a valid target where needed.
7. Visual entities require accessible descriptions.
8. Drag/drop/adjust/place actions require a keyboard-equivalent path.
9. Feedback may not reveal the answer immediately on failure by default.
10. Every learning target must retain source/reasoning/objective provenance.
11. Deterministic replay is a required contract property.
12. `product_accepted` cannot become true inside this component.

These contracts do not by themselves prove studio-quality final output. They ensure later Strategy/DIR/MECH/COMP/BUILD layers have enough semantic information to create it, and make simplistic slide-style degradation detectable rather than invisible.
