# Section 15 GAME — Batch 01: DSL / Core Contract Foundation

## Mission
Create the expressive, safe and versioned semantic contract that every later GAME strategy, director, state, mechanic, compiler and runtime batch must obey.

This is not a slide/quiz schema. The IR is designed for rich stateful learning experiences with semantic visuals, purposeful motion/camera intent, accessible interactions, adaptive behavior, feedback, audio hooks, deterministic replay and provenance.

## Governed atomic task
`BIE-GAME-DSL-001`

## Major contract families
- canonical identity / semver / hashing
- evidence provenance
- safe typed expression AST
- learning targets / misconceptions / prerequisites
- typed state model
- accessible interaction/action/rule contracts
- semantic visual entities
- pedagogical motion and camera cues
- audio cue hooks
- feedback and adaptation contracts
- studio-grade experience quality intent
- versioned GameDocument v2
- strict typed codec and canonical round-trip
- schema registry and read-only legacy boundary
- deterministic validation receipts

## Non-goals
This batch does not implement strategy selection, mechanics execution, compiler/runtime code generation, QA automation or product acceptance. Those remain governed later Section 15 capabilities.
