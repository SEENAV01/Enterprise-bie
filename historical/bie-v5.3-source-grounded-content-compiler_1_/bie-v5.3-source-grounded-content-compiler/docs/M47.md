# M47 — Source-Grounded Content Compiler

M47 creates the provenance and grounding backbone of the BIE pipeline.

Its purpose is to ensure that generated educational content can answer:

**Where did this come from?**

## Claim taxonomy

M47 distinguishes:

- SOURCE_FACT — directly supported by the source
- DERIVED — logically derived from source material
- INFERRED — an inference that requires explicit reasoning
- ENRICHMENT — outside/additional knowledge
- EXAMPLE — illustrative content
- INSTRUCTIONAL_REPHRASE — pedagogical rewriting of source content

This distinction is critical. A useful educational explanation may go beyond the literal wording of a book, but the system must not disguise enrichment or inference as source fact.

## Evidence

Evidence records contain:
- source ID
- locator
- optional excerpt
- source type

A production ingestion pipeline should populate locators from the actual source document.

## Grounding rules

Source facts require evidence.

Inferences require reasoning notes.

Enrichment must be explicitly labeled.

Required unsupported claims block export.

## Provenance graph

Every important video element can carry:
- claim IDs
- evidence IDs
- transformations

Therefore:

Book passage
→ evidence
→ claim
→ reasoning/transformation
→ narration
→ visual object
→ final rendered element

can be traced.

## No silent correction

M47 does not silently replace source content with general model knowledge.

If the source is ambiguous, incomplete, or inconsistent, that state must remain visible to the pipeline for a later resolution step.

## Higher knowledge

This module also supports the user's earlier requirement that the system identify knowledge beyond the book.

For example:

BOOK FACT
→ source-grounded

HIGHER CONCEPT
→ INFERRED / DERIVED

OUTSIDE KNOWLEDGE
→ ENRICHMENT + external evidence

Thus higher-level knowledge can be added without falsely claiming it came from the book.

## Export gate

The quality gate prevents unsupported required claims from reaching final production.

Optional exploratory content can be retained with explicit status for review.

## Next
