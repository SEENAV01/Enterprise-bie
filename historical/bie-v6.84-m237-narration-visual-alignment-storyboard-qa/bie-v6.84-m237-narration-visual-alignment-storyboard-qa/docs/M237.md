# M237 — Educational Narration Quality, Scene-to-Concept Visual Alignment, On-Screen Text Planning & Pedagogical Storyboard QA

```text
Script / Narration
       ↓
 Narration QA
       ↓
Scene + Concept Mapping
       ↓
Visual Alignment QA
       ↓
On-Screen Text Plan
       ↓
Pedagogical Storyboard QA
       ↓
   Final QA Gate
```

## Narration quality
The module scores basic clarity and conciseness signals and detects configured filler words.

## Visual alignment
Each script segment can declare concept IDs; each shot declares the concepts it visually represents. Alignment is measured from the intersection.

## On-screen text
Text overlays are generated per segment and validated against a configurable word-density limit.

## Pedagogical storyboard QA
The combined gate checks segment/shot counts, segment/text counts and concept-to-visual alignment.

## Boundary
M237 provides deterministic planning and QA heuristics. Production systems can add LLM-based factuality checks, subject-specific pedagogy, reading-level analysis, WCAG typography checks and human review.
