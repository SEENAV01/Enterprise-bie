# M109 — Learning Outcome Evaluation & Adaptive Policy Optimization

M109 closes the adaptive learning loop.

M108 selects a next-best action.

M109 asks whether the selected action produced an observed learning outcome.

## Outcome record

An outcome can link:
- learner
- action
- target concepts/objectives
- pre-action state
- post-action state
- mastery delta
- latency
- cost
- metadata

This makes action effectiveness measurable.

## Evaluation

The reference evaluator uses an explicit mastery-gain threshold.

This is intentionally simple.

A production system can later use richer evaluation models, but the architecture should keep the evaluation rule explicit and versioned.

## Why outcome evaluation matters

A weak learner result does not automatically imply learner failure.

Possible causes include:
- poor action choice
- unsuitable difficulty
- inadequate explanation
- prerequisite gap
- misconception
- measurement noise
- insufficient evidence

M109 therefore records outcome evidence before changing policy.

## Adaptive policy optimization

Policies can be versioned.

Candidate policy changes should pass evidence thresholds before being accepted.

This prevents one anomalous learner interaction from silently changing the behavior of the entire system.

## Experimentation

Alternative sequencing strategies can be represented as experiment variants.

A future experimentation system can compare:
- learning gain
- retention
- time
- completion
- error reduction
- cost

subject to safety and quality guardrails.

## Closed loop

```text
M108 chooses action
      ↓
Action executed
      ↓
Learner response
      ↓
M107 updates state
      ↓
M109 evaluates outcome
      ↓
Evidence accumulates
      ↓
Policy candidate
      ↓
Experiment / validation
      ↓
Versioned policy update
      ↓
M108 uses improved policy
```

## Important boundary

The system should not continuously self-modify from raw interaction data.

Policy updates should be:
- evidence-backed
- versioned
- attributable
- reversible
- guardrailed

This connects directly to M100 governance and provenance.

## Relationship

M107 measures learner state.

M108 chooses actions.

M109 evaluates the consequences of those choices and provides controlled feedback to future decision policies.
