# M119 — Secure Execution & Sandbox Runtime Contract

M119 defines the runtime contract for executing generated code safely inside an explicitly constrained environment.

## Execution flow

```text
Generated Code
      ↓
Sandbox
      ↓
Resource / Network / Filesystem / Process Controls
      ↓
Execute
      ↓
Artifact-only Output
      ↓
Validation
      ↓
Promotion
```

## Resource limits

A sandbox can declare:
- CPU budget
- memory budget
- disk budget
- execution timeout
- maximum process count
- maximum output size

The runtime implementation is responsible for enforcing these limits.

## Network

The reference policy supports:
- DENY
- ALLOWLIST

Network access is not implicitly available to generated code.

An allowlist can restrict outbound access to explicit hosts.

## Filesystem

The contract separates read roots from a designated write root.

Generated execution should write only declared artifacts to the output area.

Deletion can be separately controlled.

## Processes

Executable permissions are explicit and process counts are bounded.

A production runtime should enforce these restrictions at the OS/container/runtime level.

## Artifact-only output

The expected output channel is an artifact contract:

```text
artifact ID
path
hash
MIME type
size
```

Arbitrary side effects are not treated as valid output.

## Termination

Timeout and resource failures should have explicit termination records.

This makes failure reason distinguishable from ordinary application errors.

## Promotion

A sandbox artifact is not automatically trusted.

Promotion requires:
- source zone = SANDBOX
- target zone = WORKER
- a validation reference

M118 trust boundaries and M115 validation therefore form the promotion prerequisites.

## Important boundary

M119 is a runtime contract, not a claim that these restrictions are enforced by Python alone.

Actual isolation must be implemented by a secure execution substrate such as containers, VMs, OS sandboxing or equivalent infrastructure.

## Relationship

M118 defines trust zones.

M119 defines what the sandbox runtime must enforce inside those zones.

M115 validates artifacts before promotion.

M101–M104 orchestrate jobs that consume this execution contract.
