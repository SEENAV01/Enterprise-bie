# M283 — Grounded Knowledge Compiler

M283 is the first real knowledge-layer implementation after the book structure compiler.

```text
Document IR 2.1
      +
Book Structure
      ↓
Evidence Index
      ↓
Source-grounded Claims
      ↓
Conservative Entity Candidates
      ↓
Evidence-backed Relations
      ↓
Knowledge IR 1.0
      ↓
Grounding Validation
      ↓
Planning
```

## Implemented

- source evidence index
- source-grounded claims
- conservative entity candidates
- explicit evidence-backed relations
- grounding validation
- QA gate for knowledge grounding
- Knowledge IR 1.0
- tests and contract
- integration into the canonical pipeline

## Critical design decision

M283 does **not** use generic co-occurrence as semantic truth. A relation is explicitly labelled `co_occurs_in_claim` and points back to a source claim.

Likewise, claims preserve source wording and source block identity. This gives later LLM planning a grounded substrate instead of an opaque pile of generated facts.

## Important boundary

This is not yet a complete ontology, vector database, semantic retrieval system, contradiction detector, or textbook-domain knowledge graph.

Those can be added behind this stable evidence/claim contract.
