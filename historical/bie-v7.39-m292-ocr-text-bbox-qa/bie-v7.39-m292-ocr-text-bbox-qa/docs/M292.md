# M292 — OCR + Text Bounding Box QA

M292 adds actual OCR to sampled rendered frames and preserves word-level bounding boxes and confidence.

```text
MP4
 ↓
Frame Samples
 ↓
Tesseract OCR
 ↓
Word Text + Bounding Boxes + Confidence
 ↓
Text QA
 ↓
Repair Plan
```

## Implemented

- Tesseract detection
- TSV OCR execution
- word-level bounding boxes
- OCR confidence capture
- low-confidence analysis
- explicit OCR dependency failure
- repair-plan generation
- QA integration
- tests + contract

## Important boundary

M292 can measure what the OCR engine sees, but OCR is not equivalent to semantic correctness.

A low OCR confidence can indicate small, low-contrast, distorted or overlapping text, but it does not by itself prove the underlying content is wrong.
