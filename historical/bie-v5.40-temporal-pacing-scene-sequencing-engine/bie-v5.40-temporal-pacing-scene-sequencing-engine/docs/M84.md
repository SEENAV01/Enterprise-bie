# M84 — Temporal, Pacing & Scene Sequencing Engine

M84 turns the structured learning experience into a temporal plan.

## Sequence

The engine represents pedagogical beats such as:
- introduction
- attention
- explanation
- demonstration
- prediction
- interaction
- practice
- feedback
- reflection
- assessment
- transition
- summary

Beats can be ordered by explicit dependencies.

## Timing philosophy

M84 does not require arbitrary fixed durations.

A timeline can carry:
- minimum/maximum constraints
- preferred timing
- event offsets
- duration signals
- dependency constraints

Actual duration can be derived later from:
- narration length
- interaction requirements
- animation complexity
- pedagogical pacing
- learner response
- production policy

This prevents early hard-coding of durations that later conflict with narration or interaction.

## Synchronization

Events can connect:
- narration cues
- visual cues
- audio cues
- interactions
- feedback
- state changes
- user actions

This creates explicit synchronization hooks for downstream audio/video rendering.

## Pacing

Pacing is represented separately from raw duration.

A segment can carry:
- density limits
- recovery time
- transition cost
- attention-window guidance

A production system can later learn or optimize these values.

## Adaptive timeline

Because M78 can produce learner decisions and M79 defines interactions, timeline execution can branch.

Examples:
- learner fails → insert remediation beat
- learner succeeds → skip redundant explanation
- learner requests repeat → revisit previous beat
- interaction takes longer → timeline waits

## Renderer independence

M84 creates a timeline specification, not Remotion code.

A downstream compiler can convert it into frame-based timelines after audio, assets and render requirements are resolved.

## Relationship

M81 → visual behavior.

M82 → reusable visual assets/components.

M83 → spatial composition.

M84 → temporal sequence and pacing.

The next layer can synchronize speech, audio, captions and visual events.
