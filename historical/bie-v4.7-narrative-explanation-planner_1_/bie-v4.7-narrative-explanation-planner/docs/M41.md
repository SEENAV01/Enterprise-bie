# M41 — Narrative + Explanation Planner

M41 converts lesson architecture into a synchronized narrative specification for downstream production.

## Purpose

M40 decides the pedagogical structure.

M41 decides how that structure should be communicated:

- spoken explanation
- visual intent
- equations
- text
- diagrams
- animations
- examples
- transitions
- learner checks

## Narrative beats

Different knowledge structures get different explanation patterns.

### Mechanism

Question
→ Cause
→ Mechanism
→ Check

### Derivation

Start
→ Step
→ Step
→ Conclusion

### Worked example

Problem
→ Setup
→ Solve
→ Verify

### Application

Scenario
→ Apply
→ Interpret

### Misconception

Claim
→ Challenge
→ Correct

These are planning structures, not fixed scripts.

## Explanation quality rules

The downstream script generator should:
- explain reasoning rather than merely announce facts
- introduce symbols before using them
- make causal links explicit
- preserve source grounding
- avoid unsupported additions
- connect each step to the learner's mental model
- avoid filler

## Visual synchronization

Visuals are planned as support for narration.

Examples:
- causal explanation → causal diagram/animation
- derivation → equation reveal/highlight
- application → scenario/diagram
- comparison → comparison visual

The visual should appear because the narration reaches the relevant cue, not because a fixed timestamp says so.

## Audio-driven timing

M41 intentionally does not assign final scene durations.

The intended production chain is:

M41 narrative specification
→ final script
→ TTS / recorded narration
→ measured audio duration
→ cue extraction
→ scene timeline
→ Remotion

Thus the spoken explanation determines the real temporal structure.

## Grounding

Narrative, equations and text events should carry source IDs or source spans where applicable.

Creative transitions may not need external evidence, but factual additions do.
