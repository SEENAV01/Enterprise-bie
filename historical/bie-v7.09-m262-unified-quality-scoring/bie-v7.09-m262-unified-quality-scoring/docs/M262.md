# M262 — Unified Quality Scoring & Multi-Modal QA Engine

```text
M261 Domain Checks
      ↓
Weighted Scoring
      ↓
Hard Failure Detection
      ↓
Scene QA
      ↓
Lesson QA
      ↓
Course QA
      ↓
Release Thresholds
      ↓
Unified QA Gate
```

## Weighted score
Visual, semantic, diagram, audio, caption and accessibility checks contribute with configurable weights. Semantic correctness is weighted more heavily by default.

## Hard failures
Critical errors can block release independently of the numeric score.

## Hierarchical QA
Scene scores aggregate into lesson scores, and lesson scores aggregate into course scores.

## Thresholds
Default release thresholds are 90 for scenes, 92 for lessons and 94 for courses.

## Gate
A release passes only when the relevant score threshold is met and no hard failure is present.

## Boundary
M262 is the unified decision/scoring layer. It consumes measurements from M261 and does not itself perform CV, DSP or semantic-model inference.
