# M275 — AI Prompt & Context Engineering Layer

```text
Task
 ↓
Prompt Template + Version
 ↓
Variable Binding
 ↓
Context Assembly
 ↓
Source Grounding
 ↓
Token Budget
 ↓
Model Inference
 ↓
Structured Output Validation
 ↓
Evaluation Hook
```

## Prompt templates
Templates are versioned and declare their required variables and optional output schema.

## Context
Relevant source records can be assembled and explicitly associated with citations/grounding requirements.

## Token budgets
Context parts are admitted until the configured token budget is reached.

## Structured outputs
Required fields are validated before downstream workflow use.

## Versioning
Template changes can be compared across versions, including template, variables and output schema.

## Evaluation
Evaluation hooks record prompt version, criterion scores and pass/fail status.

## Boundary
M275 defines prompt/context contracts. It does not implement a tokenizer, retrieval model, LLM provider, citation verifier or JSON-schema engine.
