# M247 — Worked Examples, Hint Escalation, Step-by-Step Solution Scaffolding & Answer-Reveal Control

```text
Problem
  ↓
Worked Example
  ↓
Step-by-Step Scaffold
  ↓
Concept Hint
  ↓
Strategy Hint
  ↓
Step Hint
  ↓
Partial Solution
  ↓
Full Solution (controlled)
```

## Worked examples
Examples contain a problem, ordered solution steps, final answer and difficulty.

## Scaffolding
Only the appropriate portion of the solution is exposed as the learner progresses.

## Hint escalation
Hints escalate from concept → strategy → step → partial solution → full solution. A correct response can withdraw further hints.

## Answer reveal
The full solution is blocked by default during scaffolding and is permitted after mastery or an explicit learner request.

## Boundary
M247 defines disclosure controls and scaffolding contracts. It does not determine whether a learner has genuinely mastered the concept; that signal comes from M244–M246 assessment layers.
