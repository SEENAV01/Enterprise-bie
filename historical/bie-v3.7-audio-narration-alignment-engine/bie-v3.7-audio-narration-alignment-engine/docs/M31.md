# M31 — Audio / Narration Alignment Engine

M31 connects narration/audio to exact temporal control.

## Inputs

- finalized narration text
- word timestamps from an alignment engine
- optional phrase matches
- emphasis terms
- pause points

## Outputs

The system creates a timeline of:
- word anchors
- phrase anchors
- emphasis anchors
- pause anchors
- future phoneme anchors
- semantic event mappings

## Why this matters

The renderer should not guess timing from a script's character count or from fixed scene durations.

Instead:

Narration
→ Audio
→ Alignment
→ Semantic anchors
→ Scene events
→ Animation timestamps

## Voice changes

If the voice or TTS output changes, alignment must be regenerated. Manual anchor overrides remain possible.

## Phoneme layer

Phoneme alignment is an optional higher-precision layer. It can later drive mouth movement, pronunciation-sensitive typography, very tight kinetic text and micro-animation.

## Scene duration

A scene ends according to its final narration/audio event rather than an arbitrary duration cap.

## Production note

The implementation provides the data contract and baseline alignment pipeline. A production system can plug in a high-quality speech/forced-alignment provider without changing the downstream Scene DSL.
