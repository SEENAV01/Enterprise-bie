# M291 — Frame Sampling + Readability QA

M291 samples actual rendered frames and prepares them for readability inspection.

```text
MP4
 ↓
Frame Sampling
 ↓
Image Decode / Dimensions
 ↓
Readability Report
 ↓
Repair Plan
```

## Implemented

- ffmpeg-based frame sampling
- configurable sample count
- image decoding and dimension checks
- explicit runtime dependency states
- readability QA report
- repair-plan generation
- final QA integration
- tests + contract

## Important boundary

M291 does **not** pretend that image dimensions prove that text is readable.

Actual OCR, font-size detection, contrast analysis, equation recognition and visual-semantic checks remain later layers. If a dependency is unavailable, BIE records that fact rather than fabricating a pass.
