# M107 — Learner Model, Assessment & Mastery State Layer

M107 closes the loop between the learning graph and observed learner behavior.

## Learner state

The learner model stores concept-level state rather than modifying the source knowledge graph.

A state can include:
- mastery estimate
- uncertainty
- evidence references
- status
- update time

## Evidence

Evidence is explicitly linked to:
- learner
- activity
- concepts
- response
- score/correctness
- confidence
- metadata

This allows multiple evidence types to contribute to a concept estimate.

## Mastery

Mastery is represented as an estimate plus uncertainty.

This avoids treating one answer as absolute proof of mastery.

The reference implementation provides a conservative update function and a simple classification:
- MASTERED
- DEVELOPING
- NEEDS_SUPPORT

These are planning categories, not psychometric claims.

## Assessment

Assessment items can target:
- concepts
- objectives
- difficulty
- rubric
- known misconceptions

Responses become evidence that can update learner state.

## Remediation

Rules can trigger targeted strategies when mastery is low or uncertainty remains high.

Possible strategies include:
- explanation
- worked example
- practice
- simulation
- retrieval

The actual strategy selection can later be optimized using outcome data.

## Important separation

The architecture keeps these separate:

```text
Source Knowledge
      ↓
Learning Graph
      ↓
Learner State
```

A learner struggling with a concept does not alter the underlying source truth.

Instead, learner state influences the next learning action.

## Adaptive loop

```text
Learn
 ↓
Practice
 ↓
Observe
 ↓
Assess
 ↓
Update mastery
 ↓
Estimate uncertainty
 ↓
Choose next action
 ↓
Learn again
```
