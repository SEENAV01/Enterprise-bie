# M91 — Source-Grounded Content Transformation & Generation Engine

M91 turns verified source evidence into production-ready educational artifacts.

## Transformation targets

A source fragment can be transformed into:
- explanation
- example
- analogy
- narration
- question
- activity
- visual plan
- assessment
- summary
- study guide

The output type is explicit.

## Source grounding

Each generated output can retain:
- source fragment references
- generated addition references
- objective references
- transformation metadata

This allows downstream systems to trace an output back to its evidence.

## Source-derived vs generated

The architecture explicitly distinguishes:
- `SOURCE_DERIVED`
- `GENERATED`
- `MIXED`
- `UNATTRIBUTED`

A mixed explanation might use a source definition and add a newly generated example.

That distinction must survive downstream production.

## Generation permission

A transformation request can explicitly allow or forbid generated additions.

This prevents an implementation from silently supplementing source material when the requested workflow requires strict source fidelity.

## Constraints

Transformations can enforce rules such as:
- source citation required
- ungrounded additions forbidden
- generation disabled

More constraints can be added later for:
- terminology preservation
- reading level
- length
- pedagogical strategy
- curriculum alignment
- safety/accessibility
- output format

## Traceability

M91 is intentionally not an opaque prompt wrapper.

The transformation itself is a structured object with:
- source inputs
- output target
- objectives
- instructions
- constraints

This makes transformations inspectable and reproducible.

## Production pipeline

M90 provides verified fragments.

M91 transforms them into educational artifacts.

Those artifacts can flow into:
- M77 pedagogy
- M81 visual grammar
- M84 temporal planning
- M85 speech synchronization
- M86 assessment
- M89 adaptive planning

## Important principle

The system should not silently turn model knowledge into source claims.

If the model adds information, the output can mark it as generated.
