# M86 — Assessment Item Generation & Evaluation Engine

M86 makes assessment a structured part of the learning system rather than an afterthought.

## Objective linkage

Every assessment item should reference a learning objective.

This lets the system answer:
- which objective was tested?
- which concept was tested?
- what evidence was collected?

## Item types

The base grammar supports:
- multiple choice
- multi-select
- numerical
- short answer
- open response
- prediction
- matching
- ordering
- practice
- scenario

The architecture is extensible.

## Difficulty

Difficulty is represented explicitly.

A profile can include:
- intrinsic complexity
- reasoning depth
- novelty
- overall level

A production system can later calibrate these values from learner performance.

## Misconception-aware distractors

Distractors can reference specific misconceptions.

This is important because an incorrect answer can provide more useful evidence than a simple binary wrong flag.

Example:

`choice B → misconception: confuses force with field`

M78 can use this evidence to select remediation.

## Evaluation

Evaluation rules can support:
- exact matching
- numerical tolerance
- model/human evaluation hooks

Open responses are therefore not forced into simplistic exact-match logic.

## Evidence

Every response can emit structured evidence:
- objective
- item
- correctness
- score
- misconception
- confidence

This evidence becomes an input to mastery/adaptation.

## Generation

Assessment generation specifications can constrain:
- objective
- item type
- difficulty
- concept
- misconception targets
- generation constraints

This enables controlled question generation instead of unconstrained LLM question writing.

## Quality gates

The reference compiler detects:
- missing objective references
- duplicate choices
- missing correct MCQ answers

Additional validators can later check:
- ambiguity
- answer leakage
- distractor quality
- psychometric properties
- bias/accessibility
- curriculum coverage

## Relationship

M76 → knowledge and concepts.

M77 → learning objectives.

M78 → mastery/adaptation.

M86 → assessment and evidence.

This closes the core loop:

`Teach → Interact → Assess → Diagnose → Adapt`
