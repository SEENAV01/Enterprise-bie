# M135 — Evaluation, Quality Gates & Automated Verification Layer

M135 gives BIE an explicit mechanism to judge generated outputs before they advance.

## Deterministic checks

Checks can validate objective properties of an artifact.

Examples:
- required files exist
- schema is valid
- duration is within limits
- referenced assets resolve
- output is structurally complete

A check returns an explicit pass/fail result with severity and details.

## Rubric evaluation

Quality can be represented as weighted criteria.

```text
Accuracy       40%
Completeness   25%
Clarity        20%
Consistency    15%
```

The reference implementation computes a weighted score.

Each criterion can also define its own threshold.

## Quality gates

A quality gate combines:
- evaluation score
- criterion pass/fail
- required deterministic checks

Only when the gate passes should the artifact be eligible for the next stage.

## Confidence

Evaluation confidence is explicit rather than hidden.

Confidence can incorporate:
- score
- evidence quantity
- evaluator agreement

Confidence bands are available as HIGH, MEDIUM or LOW.

## Regression detection

A new artifact/evaluation can be compared with a baseline.

```text
Current Score
     vs
Baseline Score
     ↓
Delta
     ↓
Regression?
```

This prevents a new model/prompt/policy from silently degrading output quality.

## Repair loop

A failed evaluation can produce:

```text
FAIL
 ↓
Identify Failed Checks
 ↓
REPAIR
 ↓
RE-EVALUATE
```

Retry limits should prevent infinite repair loops.

## Release eligibility

Release is allowed only when:
- quality gates pass
- regression checks pass
- minimum confidence is satisfied

This creates an automated quality barrier before publication.

## Relationship

M134 measures system operation.

M135 measures output quality.

M130 provides recovery for the workflow around these evaluations.

M133 provides policy/configuration governance for thresholds and evaluation rules.

## Important boundary

Automated evaluation does not guarantee correctness. High-impact outputs may still require human review, especially when quality criteria are subjective or the cost of an undetected error is high.
