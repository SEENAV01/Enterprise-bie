# M24 — Knowledge Graph Constructor

M24 converts grounded evidence into a structured knowledge graph.

## Graph entities

The graph can represent:
- concepts
- definitions
- laws/principles
- processes/procedures
- examples
- derivations
- questions
- applications
- conditions
- quantities
- entities
- prerequisites
- chapters/sections

## Relationships

Relationships include:
defines, explains, causes, requires, part_of, precedes, derives, applies_to, example_of, contrasts_with, depends_on, answers, measures, contains and supports.

## Evidence grounding

Every BOOK node/edge can carry evidence IDs.
This allows the lesson planner to trace a statement back to source evidence.

## Two knowledge scopes

This is critical to the user's design.

### BOOK
Knowledge explicitly supported by the source book.

### EXTERNAL_HIGHER_KNOWLEDGE
Knowledge that is not in the book but is logically useful as a higher-level extension or dependency.

These scopes must never be silently merged.

External candidates carry:
- reason for inclusion
- what book knowledge they derive from
- confidence
- verification requirement

## Why this matters

Suppose a book teaches Ohm's law. The system may identify later network-analysis ideas as useful higher knowledge. It must represent this as an external extension, not pretend the book taught it.

## Query layer

The graph can answer:
- What does this concept depend on?
- What prerequisites are required?
- What concepts does it support?
- What higher knowledge can follow from it?

## Important boundary

M24 provides the graph architecture and explicit scope separation. It does not claim that raw text extraction alone can reliably infer every relation. Production relation extraction should use grounded model reasoning plus evidence verification.
