# M272 — Global Resource & Artifact Manager

```text
Production Outputs
       ↓
Content Hash / Artifact Identity
       ↓
Immutable Artifact Registry
       ↓
 ┌─────┼────────┐
 ↓     ↓        ↓
Resolve Dedup  Lineage
             ↓
          Retention
             ↓
      Garbage Collection
```

## Identity
Content-addressed IDs use SHA-256 over artifact bytes. Logical artifact IDs include namespace, name and version.

## Immutability
Registered artifacts are immutable records; repeated registration returns the existing record.

## Deduplication
Artifacts sharing the same content hash can be identified and a canonical artifact selected.

## Lineage
Parent relationships support ancestor traversal from releases back to source artifacts.

## Retention
Artifacts may carry expiry metadata and can be selected as garbage-collection candidates when expired.

## Boundary
M272 defines resource and artifact contracts. It does not itself provide object storage, a CDN, or destructive deletion; storage adapters can implement those operations safely.
