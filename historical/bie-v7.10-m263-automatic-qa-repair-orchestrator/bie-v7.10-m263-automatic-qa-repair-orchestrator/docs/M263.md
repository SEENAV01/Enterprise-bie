# M263 — Automatic QA Repair Orchestrator

```text
QA Failure
   ↓
Failure Diagnosis
   ↓
Repair Strategy
   ↓
Repair Job
   ↓
Targeted Re-render
   ↓
Re-validation
   ↓
 ┌───────────────┐
 │ PASS → Release│
 │ FAIL → Repair │
 └───────────────┘
```

## Diagnosis
Known validation errors map to domain-specific repair actions.

## Strategy selection
Actions resolve to target domain and execution mode such as patch, regenerate, process, or realign.

## Repair jobs
Each job records the source errors, target, mode, attempt and output.

## Targeted re-render
Only affected scene dependencies are requested for re-render rather than blindly rebuilding the entire course.

## Re-validation loop
A repaired artifact must pass QA before release. The orchestrator supports a bounded number of repair cycles.

## Safety
Unknown errors do not receive an invented repair strategy. They remain unresolved and can block release.

## Boundary
M263 orchestrates repair; actual generation, media processing, rendering and QA measurement remain delegated to M260–M262 providers/engines.
