# M281 — Structured Content Extraction

M281 extends M280's layout-aware Document IR with the structured content needed by real educational/scientific material.

```text
Layout-aware PDF
      ↓
Reading Order
      ↓
 ┌────┼───────────┐
 ↓    ↓           ↓
Tables Equations Captions
      ↓
Structured Document IR 2.1
      ↓
Knowledge / Planning
```

## Implemented

- deterministic bounding-box reading order
- conservative table candidates from extracted text
- equation-candidate detection
- figure/table caption-link contracts
- content inventory
- Document IR 2.1
- integration into the canonical pipeline
- tests and explicit confidence/provenance fields

## Important boundary

This milestone does **not** claim perfect table extraction, mathematical parsing, diagram interpretation, or multi-column semantic reconstruction. Table candidates are intentionally conservative and confidence-scored. Equation candidates preserve source text rather than pretending to produce a correct symbolic AST.

## Why this is the next bottleneck

M280 could identify that a page contains layout blocks and figures, but downstream lesson generation needs to know that a block is a table/equation/caption and retain its relationship to the source.
