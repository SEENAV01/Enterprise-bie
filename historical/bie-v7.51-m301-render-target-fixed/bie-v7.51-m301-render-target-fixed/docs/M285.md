# M285 — Teaching / Lesson Planner

M285 is the first stage that converts the structured source into an explicit teaching plan.

```text
Book Structure
      +
Grounded Knowledge
      +
Retrieval
      ↓
Teaching Units
      ↓
Evidence Selection
      ↓
Source-order Prerequisites
      ↓
Lesson Plan IR 1.0
      ↓
Script Compiler
```

## Implemented

- source-grounded teaching units
- section-level evidence selection
- teaching-role classification
- cross-section concept-link references
- deterministic source-order sequencing
- confidence-scored prerequisite edges
- lesson-plan validation
- QA integration
- Lesson Plan IR 1.0
- tests and contract

## Important boundary

M285 does not yet claim pedagogical optimality. It does not invent prerequisites as facts; inferred prerequisite edges are explicitly labelled and confidence-scored.

A later pedagogical optimizer can reorder units, insert retrieval practice, choose examples, control cognitive load and adapt to learner level while preserving the grounding contract.
