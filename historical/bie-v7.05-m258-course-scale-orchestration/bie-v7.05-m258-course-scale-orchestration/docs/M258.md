# M258 — Course-Scale Orchestration

```text
Course
  ↓
Lesson / Scene DAG
  ↓
Dependency-Aware Scheduler
  ↓
Batch Rendering
  ↓
Incremental Rebuild Planner
  ↓
Lesson + Course Progress
  ↓
Course Orchestration Gate
```

## Course DAG
Lessons or scene jobs are represented as nodes with explicit dependency edges. Topological ordering detects cycles.

## Dependency-aware scheduling
Only nodes whose dependencies are complete are eligible for scheduling, with a configurable capacity.

## Batch rendering
A batch tracks item count, completed/failed counts and terminal status.

## Incremental rebuild
Content/input fingerprints identify reusable outputs and items requiring rebuild.

## Progress
Course-level and lesson-level progress are computed from completed/failed/running scene states.

## Architecture checkpoint
The rendering system now scales conceptually from one scene to an entire course:

`Scene → Lesson → Course → Batch Scheduler → Incremental Rebuild → Progress`

The next priority should be production-scale data/asset orchestration and observability rather than simply adding arbitrary blocks.
