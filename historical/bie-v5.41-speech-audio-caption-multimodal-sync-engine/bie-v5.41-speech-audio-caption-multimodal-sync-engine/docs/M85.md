# M85 — Speech, Audio, Caption & Multimodal Synchronization Engine

M85 connects educational content to actual speech/audio timing.

## Structured narration

Narration is represented as segments rather than one opaque text blob.

A segment can carry:
- objective reference
- emphasis
- pronunciation instructions
- production notes

## Speech planning

Speech plans can specify:
- voice
- language
- rate
- pitch
- pronunciation lexicon

An estimate can be generated before audio exists, but estimated timing is not treated as actual timing.

## Actual alignment

Once speech is generated or recorded, word-level alignment can be attached.

Each word can have:
- text
- start time
- end time
- index

This provides the timing substrate for precise visual synchronization.

## Captions

Captions are first-class timeline objects.

They can be generated from aligned speech and retain references to narration segments.

## Cross-modal synchronization

Anchors connect:
- words/phrases
- narration segments
- audio events
- visual events
- animation states
- interactions

Example:

`word "field" → highlight electric-field vector`

The downstream temporal compiler can translate these anchors into renderer-specific timing.

## Audio cues

Audio cues can represent:
- sound effects
- music events
- transitions
- emphasis
- interaction feedback

## Why this matters

This layer eliminates the need to guess scene durations solely from visual assumptions.

Actual narration duration can drive:
- scene length
- animation timing
- caption timing
- visual emphasis
- transitions

## Adaptive interaction

Interactive scenes can pause or resume around learner actions.

Audio synchronization therefore remains event-based rather than being a rigid prerecorded sequence.

## Accessibility

Captions and transcript-ready structures are built into the model.

Additional accessibility validators can be added later.

## Renderer independence

M85 does not produce Remotion code.

It produces speech/audio timing and synchronization intent.

## Relationship

M84 defines temporal structure.

M85 supplies actual speech/audio timing and multimodal anchors.

Together they provide the basis for final executable timelines.
