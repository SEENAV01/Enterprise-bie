# M40 — Adaptive Lesson Architect

M40 transforms pedagogical teaching units into a complete lesson architecture.

## Architecture

A lesson can contain:

HOOK
→ OBJECTIVE
→ PREREQUISITE RECALL
→ CONTEXT
→ INTUITION
→ CORE EXPLANATION
→ MECHANISM / DERIVATION
→ WORKED EXAMPLE
→ APPLICATION
→ MISCONCEPTION CHECK
→ GUIDED PRACTICE
→ RECAP
→ ASSESSMENT

Not every lesson requires every block.

The architecture is generated from the actual teaching units.

## Presentation decisions

The system decides whether information should primarily be:
- narrated
- written as text
- visualized as a diagram
- animated
- represented as equations
- shown as a scenario
- demonstrated as worked steps
- compared

This decision is based on the knowledge type and pedagogical mode.

## Adaptation

The architect can change depth using learner state.

Beginner/low mastery can receive:
- more intuition
- additional examples
- foundational explanation

High mastery can receive:
- compact explanation
- reduced repetition

This is a framework for adaptive behavior, not a claim that mastery can be inferred perfectly from one score.

## Assessment

Assessment is tied to the teaching mode.

For example:
- derivation → reproduce/find missing step
- application → transfer to new context
- causal explanation → explain cause/effect
- comparison → distinguish cases

## Timing

M40 explicitly does NOT impose fixed concept durations.

It emits relative timing requirements only. Final duration belongs to the downstream script/audio/timeline system.

Therefore the production flow remains:

Lesson architecture
→ script
→ voice/audio
→ audio duration
→ scene timeline
→ Remotion
