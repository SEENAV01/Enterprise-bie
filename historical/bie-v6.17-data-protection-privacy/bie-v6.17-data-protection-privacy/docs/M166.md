# M166 — Data Protection, Encryption & Privacy Controls Layer

M166 defines controls for protecting sensitive data throughout its lifecycle.

## Data classification

Data receives an explicit sensitivity level:

```text
PUBLIC
INTERNAL
CONFIDENTIAL
RESTRICTED
```

Classification can include categories and tenant context.

## Encryption at rest

Protected data can require an explicit encryption policy containing:
- algorithm
- key reference
- protection scope

The key itself remains outside BIE and is managed by M165-compatible key infrastructure.

## Field-level protection

Selected fields can use:

```text
ENCRYPT
TOKENIZE
HASH
```

The reference layer records the contract; it does not implement cryptographic transformations.

## Masking and redaction

Masking is useful when partial visibility is required.

```text
1234567890
↓
******7890
```

Redaction removes visibility completely:

```text
SSN → [REDACTED]
```

## Retention

Retention policies define when data may become deletable.

A legal hold prevents deletion even after the retention period.

```text
Retention active → KEEP
Retention expired → DELETE candidate
Legal hold → KEEP
```

## Deletion workflow

Deletion is explicit and auditable:

```text
REQUESTED
   ↓
APPROVED
   ↓
COMPLETED
```

The reference layer models the workflow and does not physically erase storage.

## Privacy boundary

Data access can be restricted by:
- tenant
- permitted purpose
- minimum-access requirement

This complements M163 tenant isolation and authorization.

## Protected-data access audit

Sensitive-data access produces an explicit audit record with subject, resource, purpose, decision and tenant.

This connects to M155 audit/compliance and M163 security events.

## Relationship

```text
M165 Secrets / Keys
        ↓
M166 Data Protection / Privacy
        ↓
M163 Security Enforcement
        ↓
M162 APIs / M161 Workflows
```

M164 policy controls can dynamically govern these protection rules.

## Important boundary

This reference implementation does not implement production encryption, tokenization, hashing, storage deletion, DLP, consent management, a privacy rights portal or a compliance certification system.
