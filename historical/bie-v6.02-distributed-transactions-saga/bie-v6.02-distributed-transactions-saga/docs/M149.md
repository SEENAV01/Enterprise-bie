# M149 — Distributed Transactions, Workflow Consistency & Saga Layer

M149 defines consistency patterns for multi-service workflows where one database transaction cannot cover all operations.

## Saga

A saga is an ordered set of steps with optional compensating actions.

```text
Step A ✓
  ↓
Step B ✓
  ↓
Step C ✗
  ↓
Compensate B
  ↓
Compensate A
```

## Explicit state

Saga state records:
- saga ID
- status
- completed steps
- failed step

Terminal states include:
- COMPLETED
- COMPENSATED
- FAILED
- PARTIAL

## Compensation

Compensation runs in reverse order of completed steps.

Compensating actions should themselves be idempotent.

Compensation is not a literal database rollback; it is a business operation that attempts to restore an acceptable state.

## Outbox

An outbox record can be stored alongside a local business transaction.

```text
Business State
      +
Outbox Event
```

A separate publisher can later deliver the event.

This reduces the risk of a committed state change with a lost event.

## Inbox

Consumers can record received message IDs.

```text
Message
  ↓
Inbox
  ↓
Already processed?
 ├── YES → Ignore duplicate
 └── NO  → Process
```

This complements M144's at-least-once delivery.

## Retry

Retry policies define maximum attempts and backoff metadata.

## Consistency

A workflow explicitly declares its consistency mode and whether partial completion is allowed.

## Distributed boundaries

A transaction boundary can identify multiple resources.

The reference model does not claim atomicity across those resources.

## Relationship

```text
M140 Workflow
      ↓
M149 Saga
      ↓
Service A
      ↓
M144 Event / Outbox
      ↓
Service B
      ↓
Failure
      ↓
Compensation
```

M148 can coordinate singleton saga ownership.

M142 stores resulting artifacts.

M134/M137 can observe and record saga execution.

## Important boundary

M149 does not implement two-phase commit, distributed consensus or a production transactional database. Sagas provide business-level consistency through forward actions and compensations.
