# M269 — Event Bus & Durable Workflow Coordination

```text
BIE Components
      ↓
 Domain Event
      ↓
 Durable Event Bus
   ┌──┴──────┐
   ↓         ↓
Subscribers  Event Store
   ↓
Deduplicated Delivery
   ↓
Workflow Trigger
   │
   └── Failure → Retry → DLQ
```

## Domain events
Events carry identity, aggregate identity, sequence and payload.

## Pub/sub
Subscribers register interest in event types and poll their event stream.

## Delivery
Delivery keys prevent duplicate acceptance by the same subscriber.

## Ordering
Aggregate sequences can be validated for duplicates and gaps.

## Dead letters
Events that exhaust retry policy can be retained with error and attempt metadata.

## Workflow triggers
Rules map event types to workflow starts and pass event payload as input.

## Boundary
M269 defines coordination contracts. A production deployment may back the bus with Kafka, NATS, Pulsar, Redis Streams, SQS/SNS or another durable broker through an adapter.
