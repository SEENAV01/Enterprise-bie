# M300 — Real Lesson End-to-End Acceptance

M300 defines the final acceptance gate for a complete BIE lesson.

```text
SOURCE → KNOWLEDGE → TEACHING PLAN → SCRIPT
→ SCENE DSL → REMOTION PROJECT → MP4 → QA → ACCEPTANCE
```

## Required artifacts

- source
- knowledge
- teaching_plan
- script
- scene_dsl
- remotion_project
- mp4
- qa_report

The gate accepts only when every artifact exists and the closed-loop QA result is `accepted`.

**Important:** this milestone creates the acceptance gate; it does not falsely claim that an actual lesson has passed without executing against real lesson artifacts.
