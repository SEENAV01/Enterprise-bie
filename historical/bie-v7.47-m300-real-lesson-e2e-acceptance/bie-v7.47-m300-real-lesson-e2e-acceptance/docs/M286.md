# M286 — Grounded Script Compiler

M286 converts the teaching plan into an executable script representation.

```text
Teaching Plan
     +
Grounded Knowledge
     ↓
Evidence Selection
     ↓
Source-derived Narration
     ↓
Script IR 1.0
     ↓
Scene Candidates
     ↓
Scene DSL Compiler
```

## Implemented

- source-grounded narration
- sentence-level source assembly
- source-block traceability
- scene candidates
- script validation
- QA integration
- Script IR 1.0
- tests and contract

## Critical rule

M286 does **not** silently embellish the source.

The baseline narration is assembled from selected evidence blocks. This creates a safe, inspectable bridge between pedagogical planning and visual production.

A later controlled transformation layer can add introductions, transitions, examples or teacher-style explanations, but those should remain explicitly typed and distinguishable from source-derived claims.
