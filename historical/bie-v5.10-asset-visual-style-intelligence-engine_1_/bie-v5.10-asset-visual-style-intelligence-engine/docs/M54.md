# M54 — Asset & Visual Style Intelligence Engine

M54 provides course-level visual identity and asset continuity.

## Why it exists

Long-form educational generation can fail even when each individual scene looks good.

Typical failures:
- a character changes appearance between lessons
- the same object is redrawn with different proportions
- diagram conventions change
- typography drifts
- motion language becomes inconsistent
- every scene invents new assets unnecessarily

M54 treats visual consistency as structured data.

## Style Bible

A style bible stores:
- visual tokens
- typography
- layout rules
- diagram conventions
- camera language
- motion conventions
- other course-level design rules

## Semantic Asset Library

Assets have:
- stable IDs
- semantic roles
- types
- versions
- optional variants

A scene references an asset rather than recreating an equivalent object blindly.

## Visual Grammar

Visual grammar maps meaning to conventions.

Examples:
- definition → title + highlight
- causality → directional arrow
- comparison → split layout
- important result → controlled emphasis

The actual conventions are configurable per course.

## Motion Language

Motion rules map semantic events to motion.

Examples:
- introduce → reveal
- change parameter → controlled transformation
- causal relationship → directional movement
- focus → emphasis

This prevents decorative animation from becoming the default language.

## Continuity

The system tracks course-level style, grammar, assets and motion rules.

Changes are explicit and traceable rather than silently drifting.

## Reuse

The system prefers an existing semantic asset when a suitable one exists.

A new asset should be created when:
- no suitable asset exists
- the semantic role genuinely differs
- a deliberate version change is approved

## Relationship to previous modules

M52 defines scientifically meaningful visual structures.

M53 defines valid model behaviour.

M54 defines how those structures consistently look and move across the course.

Therefore:

`Meaning → Valid State → Consistent Visual Language → Animation`
