# M280 — Layout-Aware Document Understanding

M280 closes the first major gap after source intake: a plain text stream is insufficient for books and course material.

## Pipeline

```text
PDF
 ↓
Page Layout Extraction
 ↓
Text Blocks + Bounding Boxes
 ↓
Block Classification
 ├─ Paragraph
 ├─ Heading
 ├─ Semantic Block
 ├─ Equation Candidate
 └─ Figure
 ↓
Section Hierarchy
 ↓
Document IR 2.0
 ↓
Knowledge / Planning
```

## Implemented

- PyMuPDF page-aware PDF extraction
- bounding boxes
- block-level classification
- heading detection
- section hierarchy
- explicit figure/image blocks
- equation-candidate detection
- optional Tesseract OCR adapter
- explicit OCR-required state for image-only PDFs
- canonical pipeline integration
- tests and contracts

## Important non-claims

This is not yet a complete scientific document parser.

Tables, high-fidelity mathematical structure, captions, multi-column reading order, footnotes, diagrams and semantic figure interpretation still require dedicated adapters.

OCR is implemented as an explicit adapter, but it requires the local Tesseract runtime in addition to the Python package. It is not silently assumed to exist.
