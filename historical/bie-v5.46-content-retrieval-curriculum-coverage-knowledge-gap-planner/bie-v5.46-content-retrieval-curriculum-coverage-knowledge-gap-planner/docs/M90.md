# M90 — Content Retrieval, Curriculum Coverage & Knowledge-Gap Planner

M90 connects the learning model to actual source material.

## Sources

Sources can represent:
- books
- PDFs
- articles
- videos
- courses
- notes
- transcripts
- web material
- datasets
- other source types

## Content fragments

Retrieved fragments retain:
- source reference
- text
- locator
- concept references
- objective references
- provenance

This makes source-grounded generation traceable.

## Retrieval

Retrieval queries can be expressed using:
- objectives
- concepts
- terms
- filters
- top-k limits

Ranking signals remain replaceable.

## Coverage

Coverage is tracked per objective/concept.

Statuses include:
- covered
- partially covered
- missing
- conflicting
- insufficient evidence
- generate

This distinction is important.

For example, a source may mention a concept but not explain it deeply enough for the target learner.

## Knowledge gaps

Open gaps can represent:
- missing content
- insufficient depth
- missing prerequisite
- conflicting sources
- missing representation
- missing example
- missing assessment

## Generation boundary

M90 does not automatically replace source material with model knowledge.

When source evidence is insufficient, it explicitly marks the gap and can emit a `GENERATE` action.

Downstream policy can then decide whether generation is allowed and how it must be labeled.

## Provenance

Source-grounded fragments retain a trace back to the original source and locator.

This supports:
- citations
- auditability
- review
- source comparison
- debugging

## Curriculum completeness

By comparing target references with coverage records, the system can identify which parts of a curriculum are:
- sufficiently sourced
- partially sourced
- unsupported
- conflicting

## Relationship

M76/M77 define knowledge and objectives.

M90 finds and maps source evidence.

M89 uses coverage availability when choosing learning actions.

M91 can build the source-grounded generation and transformation pipeline from these verified fragments.
