# M146 — Configuration, Feature Flags & Dynamic Policy Layer

M146 allows BIE behavior to change through governed runtime configuration rather than requiring a code redeploy for every operational change.

## Typed configuration

Configuration values declare a type such as:
- string
- integer
- number
- boolean
- object
- array

Validation occurs before accepting a value.

## Environment overlays

Configuration can be layered by environment.

```text
Defaults
  ↓
Environment Overlay
  ↓
Effective Configuration
```

The reference resolver applies overlays by priority.

## Feature flags

Flags support:
- enabled state
- percentage rollout
- version
- kill switch

## Deterministic rollout

A subject is deterministically bucketed using a hash of:

```text
flag_id + subject
```

The bucket is compared with the rollout percentage.

This keeps a subject consistently inside or outside a rollout for the same flag.

## Kill switches

A kill switch can immediately make a flag inactive in the policy model.

## Dynamic policies

Policies carry:
- ID
- version
- rules
- enabled state

Services can resolve governed runtime behavior from the effective policy.

## Safe updates

Updates can include an expected version.

If the current version differs, the update fails with a version conflict.

This provides an optimistic-concurrency foundation.

## Rollback

Revision records preserve historical configuration values and versions.

A previous revision can be selected for rollback planning.

## Audit

Configuration changes record:
- actor
- action
- key
- old version
- new version
- timestamp
- reason

## Relationship

```text
M145 API
   ↓
Configuration Request
   ↓
M146 Policy / Flag
   ↓
Effective Runtime Config
   ↓
M140/M141/M143/etc.
```

M143 remains responsible for secrets; M146 must never be used as a raw secret store.

## Important boundary

The reference implementation is a policy/configuration model. It does not provide a distributed configuration database, consensus, secure remote update channel, production feature-flag service or atomic multi-service rollout.
