# M232 — Learner Modeling, Skill Tracing, Knowledge-State Persistence & Personalized Lesson Selection

```text
Learner
   ↓
Assessment Responses
   ↓
Skill Tracing
   ↓
Skill-Level Mastery State
   ↓
Persistent Knowledge State
   ↓
Personalized Lesson Selection
```

## Learner model
A stable learner ID anchors the personalized state.

## Skill tracing
Assessment responses are linked to one or more skills and converted into skill evidence.

## Knowledge state
Skill mastery and evidence counts are persisted as a versioned learner knowledge state.

## Updates
New response evidence updates skill mastery using a weighted incremental estimate.

## Personalized selection
Lessons are scored by unmet skill mastery and the lowest-mastery required skills receive higher priority.

## Boundary
M232 defines deterministic state contracts. Production systems can add richer learner profiles, Bayesian knowledge tracing, IRT, forgetting curves, privacy controls and cohort-level personalization.
