# M38 — Universal Content Decomposer

M38 implements the core content-understanding operation requested for the project: decompose the complete book across multiple knowledge/question dimensions instead of reducing it to a list of concepts.

## The decomposition dimensions

The baseline schema supports:

WHAT
WHY
HOW
WHEN
WHERE
WHO
DEFINITION
PROCESS
CAUSE
DERIVATION
EXAMPLE
APPLICATION
ASSUMPTION
EXCEPTION
EVIDENCE
PREREQUISITE
DEPENDENCY
COMPARISON
LIMITATION
COUNTEREXAMPLE
SEQUENCE
MECHANISM
FORMULA
OBSERVATION
CONCLUSION

A single passage may legitimately map to multiple dimensions.

## Source grounding

Every extraction carries a source span. The system therefore knows where the extracted information came from.

This is critical because the decomposition layer should not silently rewrite the book and then lose the relationship between extracted knowledge and source text.

## Full-content preservation

M38 does not replace the original book with extracted concepts. The source segments remain part of the representation.

The extracted dimensions are an analytical layer over the source.

## Why this is better than simple concept extraction

A concept list cannot adequately represent:
- why something happens
- how a process works
- when a condition applies
- where something is observed
- who contributed to an idea
- how a derivation proceeds
- what assumptions are required
- what exceptions exist
- how knowledge is applied
- what later knowledge depends on it

M38 explicitly creates structures for these.

## Multi-dimensional representation

Example:

"Potential difference causes charges to move."

can produce:

WHAT → potential difference
WHY → why current occurs
CAUSE → potential difference causes charge movement
HOW → mechanism/process
DEPENDENCY → current depends on charge movement conditions

The final mapping should be determined from the actual source, not blindly generated from keyword matches.

## Coverage

The coverage module reports which dimensions were found and which are absent. An absent dimension is not automatically an error: some sections genuinely contain no person, date, derivation, application, etc.

Coverage is therefore a diagnostic, not a requirement that every passage contain every dimension.

## Derivations

Derivations are represented as ordered steps with dependencies between steps. This allows later lesson planning to animate the reasoning rather than merely display the final formula.

## Critical boundary

M38 extracts and structures source content.

It does not yet decide:
- pedagogical importance
- lesson order
- scene duration
- animation
- voice
- higher knowledge

Those remain downstream decisions.

## Next
