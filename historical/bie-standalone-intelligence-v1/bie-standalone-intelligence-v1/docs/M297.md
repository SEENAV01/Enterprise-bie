# M297 — Full Closed-Loop Video QA

M297 unifies the QA and repair milestones into one bounded execution loop.

```text
Render
  ↓
Frame Sampling
  ↓
OCR / Readability
  ↓
Equation + Diagram QA
  ↓
Semantic Comparison
  ↓
Decision
 ├── ACCEPT → publish
 ├── REVIEW → human/next-stage review
 └── REJECT
       ↓
   Grounded Repair
       ↓
   Re-render
       ↓
      QA again
```

## Implemented

- single closed-loop orchestrator
- bounded repair cycles
- explicit repair/rerender failure handling
- cycle history for auditability
- terminal accept/review/failure states
- tests + contract

## Important

M297 is the orchestration layer. It uses injected implementations of render, QA and repair so the core loop remains testable and does not silently substitute fake results.
