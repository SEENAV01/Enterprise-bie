# M105/M106 — Semantic Knowledge Graph → Learning Graph & Pedagogical Planning

M105 established semantic representation. M106 now turns that representation into an explicit learning graph and pedagogical planning layer.

## Why this is separate

A source knowledge graph describes what the material contains.

A learning graph describes how a learner should encounter and master that material.

These are related but not identical.

## Learning objectives

Objectives are explicit and can include mastery criteria and priority.

This prevents production from becoming an aesthetic-only optimization.

## Prerequisites

Concept relations can declare prerequisite structure.

The planner can compute prerequisite closure and derive a topological learning order.

If a cycle is present in prerequisite relations, the plan is rejected rather than silently inventing an order.

## Misconceptions

Misconceptions are first-class objects with:
- target concept
- diagnostic signals
- remediation strategies
- evidence references

This enables the eventual system to design explanations and assessments around likely failure modes.

## Pedagogical plan

A learning step can specify:
- concepts
- objectives
- strategy
- modalities
- assessment
- misconception references

Examples of strategy labels can include:
- explain
- example
- worked example
- retrieval
- practice
- simulation
- comparison
- reflection

These are planning primitives, not claims that one strategy is universally optimal.

## Learner adaptation

The plan structure leaves room for a learner model and constraints.

Future layers can use:
- prior mastery
- pace
- errors
- preferences
- accessibility constraints
- assessment results

to choose among valid learning paths.

## Critical architectural boundary

The system should not confuse:
1. what is stated by the source,
2. what is inferred semantically,
3. what pedagogy recommends,
4. what production chooses to render.

Those layers remain separately represented and linked.

## Relationship

M105: semantic knowledge representation.

M106: learning representation and pedagogical planning.

M102: production dependency graph.

The learning graph can produce production requests, but the production graph remains a separate engineering representation.
