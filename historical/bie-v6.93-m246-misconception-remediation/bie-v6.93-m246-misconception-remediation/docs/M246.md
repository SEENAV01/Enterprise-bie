# M246 — Misconception Detection, Error Taxonomy, Hint Generation, Remediation Planning & Mastery Reassessment

```text
Learner Error
      ↓
Error Taxonomy
      ↓
Misconception Detection
      ↓
Targeted Hint
      ↓
Remediation Plan
      ↓
Reassessment
      ↓
Mastery Update
      ↓
Progress / Remediate
```

## Error taxonomy
The baseline taxonomy includes definition confusion, formula selection, unit error, sign/direction, causal reasoning, prerequisite gap and calculation errors.

## Misconception detection
Repeated classified errors are aggregated into misconception candidates with a simple confidence score.

## Hints
Hints are selected from the error type and concept, giving the learner a targeted next step without immediately revealing the answer.

## Remediation
Detected errors create reteach-and-practice actions and mark reassessment as required.

## Reassessment
Post-remediation mastery is compared with pre-remediation mastery. The loop progresses when the mastery threshold is met; otherwise remediation continues.

## Boundary
M246 provides deterministic scaffolding contracts. Reliable misconception inference requires richer response traces, calibrated diagnostic items and validated learner models.
