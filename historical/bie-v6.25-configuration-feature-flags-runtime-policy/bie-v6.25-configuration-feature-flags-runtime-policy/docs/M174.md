# M174 — Configuration, Feature Flags & Runtime Policy Layer

M174 defines runtime configuration and controlled behavior-change contracts.

## Typed configuration

Configuration values explicitly declare a type:

```text
string
integer
number
boolean
json
```

Each value may identify its source and scope.

## Hierarchical scopes

Configuration can be resolved across scopes such as:

```text
GLOBAL
  ↓
TENANT
  ↓
WORKFLOW
```

More specific scopes receive higher priority in the reference model.

## Defaults

A default value provides fallback behavior when no explicit value exists.

## Validation

Rules can define:
- required
- allowed values
- minimum
- maximum

Invalid runtime configuration should fail validation before being activated.

## Secret references

Secrets are represented as references:

```text
SECRET_REFERENCE
```

M174 does not store raw secret material.

M165 remains responsible for secret/key management.

## Dynamic reload

Reference modes:

```text
ON_CHANGE
PERIODIC
MANUAL
```

A configuration may explicitly require restart rather than hot reload.

## Feature flags

Flags separate deployment from behavior activation.

A flag can have a default state and description.

## Rollout

Reference strategies:

```text
ALL
NONE
PERCENTAGE
SEGMENT
```

This supports staged feature activation.

## Runtime policy

Policies express an allow/deny decision with conditions and priority.

Actual policy semantics must integrate with M164.

## Observability

Configuration operations record:
- key
- operation
- status
- scope
- source

This feeds M150 telemetry.

## Relationship

```text
M163 Authorization
       ↓
M164 Policy
       ↓
M174 Runtime Configuration
   ↙        ↓        ↘
M165      M161       M150
Secrets  Runtime    Telemetry
```

M171 may distribute configuration-change events.

M173 coordination may protect configuration ownership/update operations.

## Important boundary

The reference layer does not implement Consul, Vault, LaunchDarkly, OpenFeature providers, environment-variable loaders, remote config clusters or a production policy engine.
