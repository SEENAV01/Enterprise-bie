# M101 — Secure Resource & Execution Isolation Layer

M101 establishes the security boundary around production execution.

## Core principle

Generation intent is not execution permission.

A model, planner or document can request an operation, but the execution environment independently decides whether that operation is permitted.

## Execution envelope

Every production job can carry an execution envelope containing:
- job identity
- inputs
- outputs
- permissions
- budgets
- network policy
- filesystem policy
- environment

## Permissions

Permissions are explicit for resources such as:
- filesystem
- network
- processes
- devices
- secrets

The reference policy defaults to deny for sensitive capabilities.

## Resource budgets

Jobs can be constrained by:
- CPU time
- memory
- GPU time
- wall-clock time
- storage
- output size

Budget checks prevent runaway jobs from becoming unlimited resource consumers.

## Network

Network access can be:
- denied
- allowlisted
- controlled by a policy

This is important when processing untrusted documents or generated code.

## Filesystem

Inputs and outputs can be restricted to declared roots.

The reference policy supports read-only input boundaries and controlled writable output locations.

## Isolation

The reference isolation policy expects:
- no host access
- no privilege escalation
- read-only inputs
- restricted outputs

A production implementation may enforce these through containers, sandboxes, OS isolation, VM boundaries or platform-native execution isolation.

The architecture does not assume a specific sandbox technology.

## Auditing

Execution decisions can emit audit events containing:
- job
- actor
- operation
- decision
- resource
- details
- timestamp

This connects security events to M100 provenance and M98 observability.

## Relationship

M100 establishes what should be reproducible and traceable.

M101 establishes what an execution job is actually allowed to do.

M95 can run renderers through this execution boundary.

M98 can consume execution telemetry.
