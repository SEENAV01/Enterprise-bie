# M221 — Quality-Aware Scheduling, Semantic Complexity Estimation, Difficulty-Based Resource Allocation & Render Strategy Selection

```text
Lesson Semantics
      ↓
Feature Extraction
      ↓
Complexity Score
      ├── Difficulty Level
      ├── Resource Request
      └── Render Strategy
              ↓
        Quality Profile
              ↓
          Quality Gate
```

## Semantic complexity
Features such as concepts, equations, diagrams, simulation, 3D, code and assets contribute weighted complexity.

## Quality profile
Accuracy, visual quality and pedagogy requirements are explicit inputs to execution planning.

## Resource allocation
LOW/MEDIUM/HIGH/EXTREME complexity maps to progressively larger CPU/RAM/GPU requests.

## Render strategy
Simulation and 3D requirements can select specialized GPU strategies; equation/code-heavy content can select diagram/code motion; simpler lessons use lightweight 2D strategies.

## Quality gate
The selected strategy and resource plan are checked before downstream rendering.

## Boundary
M221 defines deterministic planning contracts. Actual semantic extraction models and render backends remain implementation-specific.
