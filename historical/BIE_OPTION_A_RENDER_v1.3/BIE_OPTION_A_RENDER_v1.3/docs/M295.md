# M295 — Automatic Repair + Re-render + Regression QA

M295 moves from a repair suggestion toward an executable repair-cycle contract.

```text
Mismatch
  ↓
Grounded Repair Patch
  ↓
Safe Patch Application
  ↓
New Scene DSL
  ↓
Remotion Regeneration
  ↓
Second MP4 Render
  ↓
Before/After Semantic QA
  ↓
Regression Gate
```

## Implemented

- safe grounded patch application
- before/after Scene DSL hashes
- repair candidate artifact
- regression comparison primitive
- QA integration
- tests + contract

## Critical boundary

This milestone does not fake a second render. It prepares the repaired Scene DSL and records exactly what would be re-rendered.

The execution environment still needs to regenerate the Remotion project and perform the second render before an actual regression pass can be claimed.
