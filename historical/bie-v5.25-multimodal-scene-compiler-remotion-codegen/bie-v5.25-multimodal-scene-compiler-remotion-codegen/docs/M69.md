# M69 — Multimodal Scene Compiler & Remotion Code Generation Engine

M69 is the production bridge from educational specifications to executable video scene specifications.

## Input

M69 consumes outputs from:
- M53 domain reasoning
- M64 curriculum planning
- M65 adaptive pedagogy
- M67 visual planning
- M68 temporal/audio synchronization

## Compilation stages

`Specifications → Scene Graph → Asset Bindings → Animation Graph → Component Graph → Remotion Composition`

## Scene graph

A scene graph explicitly represents:
- scene identity
- concept references
- objective references
- visual references
- audio references
- child nodes

This keeps educational meaning separate from rendering implementation.

## Asset bindings

Every asset used by a scene should be explicitly bound.

Bindings can retain source/provenance references and renderer properties.

## Animation graph

Animation instructions specify:
- target
- property
- start/end values
- start/end times
- easing

The times originate from the temporal layer rather than an arbitrary fixed scene template.

## Remotion target

M69 emits a composition specification with:
- composition id
- component name
- duration in frames
- FPS
- dimensions

The duration is calculated from the temporal plan.

## Determinism

The compiler is intended to be deterministic: the same validated specification should produce the same scene structure and composition metadata.

This is important for:
- reproducible renders
- caching
- debugging
- regression tests
- large-course generation

## Validation

Scene graph and composition validation occur before the render stage.

M69 does not itself claim that the generated code has rendered successfully; render execution belongs to the downstream rendering layer.

## Architectural boundary

Educational/domain reasoning should not be hidden inside generated React/Remotion code.

The renderer executes a compiled specification.

## Reusability

Components are represented separately so a visual vocabulary can be reused across many scenes and lessons.

## Relationship to M67/M68

M67 decides **what visual representation** is appropriate.

M68 decides **when** it occurs relative to narration.

M69 compiles both into a renderable scene representation.
