# M20 — High-Fidelity Visual Renderer

M20 moves from visual placeholders toward structured production rendering.

## Mathematical rendering

Equations are represented as LaTeX renderer instructions.
The renderer can reveal equations step-by-step and synchronize term emphasis to narration markers.

## Diagram reconstruction

A textbook diagram can be represented as editable structured data:
- labels
- relationships
- description
- source asset reference

This allows the renderer to animate parts of a diagram instead of treating it as a flat image.

## Charts and tables

Charts and tables have explicit reveal actions:
- draw axes
- reveal data
- highlight patterns
- reveal rows
- highlight cells
- compare rows

## Media composition

Images/video/audio can be treated as layers with position, fit and z-order.

## Camera system

Supported choreography includes:
static, slow push-in, slow pull-out, pan, zoom, focus and path-following.

Camera movement is subordinate to explanation and should never distract from the learning objective.

## Audio synchronization

All high-fidelity actions use marker-driven synchronization.
The authoritative timeline remains actual narration/audio duration.

## Important limitation

This milestone defines production-grade renderer contracts and primitives. It does not claim that a placeholder component is already a polished visual renderer. The next implementation phase should wire these specifications to actual SVG/canvas/LaTeX/media rendering and asset generation.
