# M261 — Media Quality & Semantic Validation

```text
Generated Media
      ↓
Visual + Semantic Validation
      ↓
Diagram Structure
      ↓
Audio Duration/Loudness/Clipping
      ↓
Caption Synchronization
      ↓
Accessibility
      ↓
Unified Validation Result
      ↓
Repair Candidates
```

## Visual
Checks output presence and required metadata.

## Semantic
Checks that expected concepts are represented in the media metadata contract.

## Diagram
Checks node labels and edge references.

## Audio
Checks URI, duration tolerance, optional LUFS range and clipping flag.

## Captions
Checks timing order, audio bounds and non-empty text.

## Accessibility
Checks contrast, narration and caption presence.

## Output
The engine produces a quality score, hard errors and domain-specific repair candidates.

## Boundary
M261 defines validation contracts; it does not use computer vision/audio DSP by itself. Production adapters can populate richer measurements from actual media probes/models.
