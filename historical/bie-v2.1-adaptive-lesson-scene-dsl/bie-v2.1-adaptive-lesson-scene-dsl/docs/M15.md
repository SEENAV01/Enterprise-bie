# M15 — Adaptive Lesson Planner + Scene DSL

M15 converts the Knowledge Graph into a teachable sequence.

## Learning unit

Each unit contains:
- objective
- source evidence
- question-type coverage
- mastery gate
- scene sequence

## Scene DSL

The planner does not generate Remotion code yet.
It generates an intermediate Scene DSL:

definition
causal_explanation
process_animation
derivation
application
checkpoint

This separation is deliberate:
Knowledge → pedagogy → scene specification → renderer.

## Adaptive behavior

The same lesson can branch based on mastery:
- < 0.60 → reteach
- 0.60–0.80 → practice
- 0.80–0.90 → application
- > 0.90 → advance/skip

Prerequisite failure overrides mastery of the current unit.

## Question matrix

The What/Why/How/When/Where/Who/Derivation/Application matrix is used as a coverage signal, not as a forced template. A question type is included only when evidence supports it.

## Video architecture

The final production pipeline becomes:

Book → BIE → Knowledge Graph → Lesson Plan → Scene DSL → Remotion Renderer.

Next: M16 should build the Scene DSL into a renderer-ready contract for Remotion, including timing, narration, visual assets, equations, transitions, camera movement and checkpoint interactions.
