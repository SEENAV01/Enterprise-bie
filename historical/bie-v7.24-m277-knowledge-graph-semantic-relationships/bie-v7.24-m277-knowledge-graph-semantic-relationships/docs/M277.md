# M277 — Knowledge Graph & Semantic Relationship Layer

```text
Documents / Assets
       ↓
Entity Extraction
       ↓
Entity Resolution
       ↓
Typed Relations
       ↓
Knowledge Graph
       ↓
Relationship Traversal
       ↓
Provenance
       ↓
Graph-Aware Retrieval
```

## Entities
Entities have stable IDs, semantic types, names and attributes.

## Relationships
Relations connect source and target entities through typed predicates and carry provenance.

## Entity resolution
The baseline resolver performs normalized exact-name matching and returns ambiguity candidates.

## Traversal
The graph supports bounded-hop neighborhood traversal with optional predicate filtering.

## Provenance
Relationships can retain source ID, source version and locator information.

## Graph-aware retrieval
Retrieval returns graph paths and their relation evidence, enabling downstream grounded context to use relationship structure.

## Boundary
M277 defines graph semantics and retrieval contracts. It does not prescribe an ontology, graph database, entity-linking model or production knowledge-extraction pipeline.
