# M228 — Course/Book Structure Ingestion, Chapter/Section Mapping, Lesson Decomposition & Complete Learning-Path Planning

```text
Book / Course
      ↓
Outline Ingestion
      ↓
Chapter Mapping
      ↓
Section Mapping
      ↓
Concept Decomposition
      ↓
Lesson Units
      ↓
Knowledge/Concept Order
      ↓
Complete Learning Path
      ↓
Learning-Path Gate
```

## Structure ingestion
The engine accepts a normalized outline containing chapters, sections and metadata.

## Hierarchical mapping
Sections retain their parent chapter IDs. Orphan sections are rejected.

## Concept decomposition
Sections are converted into concept records and then grouped into lesson units.

## Lesson decomposition
A configurable maximum concept count controls how concepts are grouped into individual lesson units.

## Learning path
Lessons are ordered using the supplied concept dependency order while preserving course and section structure.

## Validation
The pipeline checks structural integrity, concept-to-section mapping and duplicate lesson ordering.

## Boundary
M228 defines normalized ingestion and planning contracts. Production adapters can parse PDF, DOCX, EPUB, HTML, LMS exports or other source formats before normalization.
