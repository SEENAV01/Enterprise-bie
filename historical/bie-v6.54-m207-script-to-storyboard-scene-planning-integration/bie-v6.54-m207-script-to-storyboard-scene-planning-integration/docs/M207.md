# M207 — Script-to-Storyboard & Scene Planning Integration

M207 connects the verified M206 teaching script to visual production planning:

```text
Verified Teaching Script
          ↓
      Scene Plan
          ↓
       Storyboard
          ↓
 Visual + Narration Binding
          ↓
 Objective Coverage + Timeline
          ↓
   Production-Ready Plan
```

## Scene planning

Each scene has a purpose, scene type, source script blocks, objectives, duration and order.

## Storyboard

The storyboard preserves scene ordering and defines the production canvas and broad visual style.

## Visual planning

Visuals are explicitly typed as text, diagram, chart, equation, image, icon, character, screen capture, animation or none.

## Narration binding

Narration links bind script blocks to scene time ranges.

## Coverage and timing

The integration validates objective coverage and scene continuity while maintaining a timeline.

## Evidence

Visual/evidentiary scenes can retain evidence IDs and source-record IDs from M203.

## Provenance and verification

The storyboard remains traceable to the lesson/script and upstream evidence and must pass an explicit verification gate.

## Boundary

M207 does not render video, synthesize voice, generate images, animate assets or choose a particular rendering engine. It defines the canonical production plan those systems consume.
