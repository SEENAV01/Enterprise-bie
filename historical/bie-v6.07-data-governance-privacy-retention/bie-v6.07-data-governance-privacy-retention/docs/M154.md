# M154 — Data Governance, Privacy & Retention Layer

M154 attaches governance metadata and lifecycle controls to BIE data and artifacts.

## Classification

Supported classification labels:

```text
PUBLIC
INTERNAL
CONFIDENTIAL
RESTRICTED
```

Classification can identify an owner and reason.

## Privacy

Privacy metadata can indicate:
- category
- whether data contains PII
- whether special handling is required

The reference layer does not attempt to infer PII automatically.

## Retention

Retention policies define:
- policy ID
- duration
- action
- optional legal basis

A resource becomes retention-expired when the elapsed period reaches the policy duration.

## Holds

A legal or operational hold can prevent deletion while active.

```text
Retention Expired
      ↓
    Hold?
   /     \
 YES      NO
 ↓         ↓
PRESERVE  DELETE ELIGIBLE
```

## Data lineage

Lineage records parent resources and transformations.

This provides a foundation for tracing how an artifact or dataset was derived.

## Residency

A resource can declare allowed regions and its actual region.

A mismatch marks the resource non-compliant under the reference rule.

## Controlled deletion

Deletion is modeled as a stateful request:

```text
PENDING
   ↓
Evaluate
 ├── HOLD → HELD
 ├── Not expired → NOT_ELIGIBLE
 └── Expired + no hold → APPROVED
```

Actual destruction is outside this reference layer.

## Tenant boundaries

Resources carry tenant ownership so governance operations can preserve tenant isolation.

## Audit

Governance actions can be recorded with actor, resource, action, outcome and reason.

## Relationship

```text
M153 Secure Material
        ↓
M154 Governance Metadata
        ↓
Classification
Privacy
Retention
Lineage
Residency
Deletion
```

M152 authorization remains responsible for access decisions.

M150 provides telemetry, but governance-sensitive data should not be leaked into logs or traces.

## Important boundary

The reference implementation does not implement a legal compliance engine, DLP scanner, PII detector, physical deletion engine, immutable legal-hold store or jurisdiction-specific legal interpretation.
