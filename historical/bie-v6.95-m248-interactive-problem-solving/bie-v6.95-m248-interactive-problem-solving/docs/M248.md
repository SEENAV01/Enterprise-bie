# M248 — Interactive Problem Solving, Learner Step Validation, Dynamic Hints & Real-Time Solution State

```text
Problem
  ↓
Interactive Session State
  ↓
Learner Step Response
  ↓
Step Validation
  ├── Correct → Advance
  └── Incorrect → Escalate Hint
                       ↓
                  Retry Step
  ↓
Real-Time Solution State
  ↓
Completion Gate
```

## Interactive state
A session tracks the current step, responses, hint level and completion status.

## Step validation
Responses can be checked against an expected answer or accepted variants.

## Dynamic hints
Incorrect responses escalate from concept to strategy to step, partial and full guidance. Correct responses reset the hint level and advance the learner.

## Real-time state
Every turn updates the learner's position and response history, allowing the UI/video layer to render the current solution state.

## Boundary
M248 defines the interactive state machine and deterministic validation contract. Production systems can plug in semantic answer evaluators, numerical tolerances and misconception models from later/adjacent modules.
