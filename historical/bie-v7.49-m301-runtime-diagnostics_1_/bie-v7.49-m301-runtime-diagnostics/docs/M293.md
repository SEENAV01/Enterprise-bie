# M293 — Equation + Diagram QA

M293 adds a dedicated QA boundary for mathematical and diagrammatic visuals.

```text
Source / Teaching Plan
        ↓
Script / Scene DSL
        ↓
Equation + Diagram Candidates
        ↓
OCR / Visual Primitive Inspection
        ↓
Semantic Verification Target
        ↓
Repair Plan
```

## Implemented

- equation-like OCR candidate detection
- scene equation/diagram primitive inspection
- explicit semantic verification status
- repair-plan generation
- QA integration
- tests + contract

## Critical rule

M293 **does not claim that an equation or diagram is correct merely because it is visible or recognized by OCR**.

The expected content must ultimately be compared against grounded source/teaching artifacts.
