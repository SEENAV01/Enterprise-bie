# M290 — Visual QA + Repair

M290 closes the generation loop by inspecting the rendered artifact and producing an explicit repair plan.

```text
Scene DSL
   ↓
Remotion
   ↓
MP4
   ↓
Artifact Inspection
   ↓
Visual QA Report
   ↓
Repair Plan
   ↓
Re-render / Fix
```

## Implemented

- render artifact existence and size checks
- optional ffprobe duration/stream inspection
- explicit visual QA report
- deterministic repair-plan generation
- final QA integration
- tests + contract

## Important boundary

M290 currently validates **render integrity**, not full human-level visual semantics.

It can detect missing/empty output and, when ffprobe is available, inspect duration and stream metadata. It does not yet prove that diagrams are pedagogically correct, text is readable, equations are accurate, or animations look good.

The repair plan is intentionally explicit and does not silently alter source claims.
