# M215
Course/book production is represented as a DAG.

```text
Course/Book → Dependency Graph → Topological Plan → Parallel Batch
                         ↓
                 Change Detection
                         ↓
                Affected Nodes
                         ↓
              Incremental Rebuild
                         ↓
                    Cache Reuse
```

Only changed nodes and downstream dependents enter the rebuild scope. Unaffected cached artifacts can be retained.
