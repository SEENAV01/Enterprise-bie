```text
Asset Requirement

       ↓
 ┌───────────────┬────────────────┬────────────────┐
 Dimensions   Semantics      Modalities       Metadata

                         ↓
                    Generation Gate
                         ↓
                     Provenance
```

## Generation planning
The engine selects a generation method based on asset type and requirements.

## Templates
Reusable templates define required parameters and defaults. Instances can override defaults while missing required parameters are rejected.

## Procedural assets
Generators receive explicit parameters and deterministic seeds, enabling reproducible assets.

## Multi-modal validation
Generated assets can be checked for required modalities such as visual/vector representations.

## Semantic validation
Required tags can verify that the generated asset represents the intended subject.

## Technical validation
Dimensions, asset type, metadata and URI are validated before downstream use.

## Provenance
Each generated asset records its source type, generator, template, and seed where applicable.

## Boundary
M223 defines generation and validation contracts; actual image/video/3D generators and ML validators remain implementation-specific.
