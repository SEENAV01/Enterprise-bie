# M201 — Canonical BIE Core

M201 is the first integration milestone after the M001–M200 foundation.

## Purpose

M201 does not add another independent feature subsystem. It establishes one canonical contract for the complete BIE educational-video production path.

Canonical stages:

```text
Source
→ Understanding
→ Knowledge
→ Pedagogy
→ Lesson
→ Script
→ Storyboard
→ Scene
→ Assets
→ Audio
→ Remotion
→ Render
→ QA
→ Publish
```

## Canonical run

A pipeline run has:
- run ID
- source reference
- canonical configuration
- ordered stage contracts
- stage status
- input/output references
- error collection

## Artifact and lineage

Every produced artifact can identify:
- artifact ID
- kind
- producer stage
- content reference
- source references
- metadata

Lineage can identify parent artifacts and original source references.

This establishes the minimum traceability boundary for source-grounded educational video generation.

## Validation

The canonical validator checks:
- run identity
- source presence
- exact canonical stage order

Completion requires every canonical stage to reach COMPLETE.

## Important boundary

M201 does not claim that every stage is already a production implementation. It creates the integration contract that later completion work must satisfy.

## Relation to previous foundation

M001–M200 remain reusable subsystem foundations. M201 becomes the canonical integration spine rather than replacing them.
