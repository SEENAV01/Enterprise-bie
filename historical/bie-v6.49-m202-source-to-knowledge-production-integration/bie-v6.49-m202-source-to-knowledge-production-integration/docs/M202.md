# M202 — Source-to-Knowledge Production Integration

M202 implements the first concrete production segment of the M201 canonical spine:

```text
SOURCE
  ↓
UNDERSTANDING
  ↓
KNOWLEDGE
```

It establishes source registration, ordered source segmentation, explicit evidence binding, grounded knowledge concepts and relationships, provenance, and PASS/FAIL/REVIEW verification.

It is an integration contract and reference implementation. It does not claim to be a complete PDF parser, OCR engine, LLM, embedding service, or graph database.

## Quality gate

```text
registered source
→ ordered segments
→ evidence
→ grounded concept
→ provenance
→ verification PASS
```
