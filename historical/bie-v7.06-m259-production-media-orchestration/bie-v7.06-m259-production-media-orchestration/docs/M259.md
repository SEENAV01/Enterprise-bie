# M259 — Production Asset & Media Orchestration

```text
Scene
 ↓
Media Dependency Graph
 ├── Images
 ├── Diagrams
 ├── TTS / Audio
 └── Captions
 ↓
Versioned Asset Registry
 ↓
Fingerprint + Deduplication
 ↓
Media Cache
 ↓
Resolved Render Assets
```

## Asset registry
Assets are typed and registered with stable IDs, URIs, versions and metadata.

## Versioning
A deterministic fingerprint captures kind, URI, version and metadata so changes invalidate dependent cache entries.

## Deduplication
Identical fingerprints are stored once and exposed through aliases.

## Media dependency graph
Scenes explicitly declare required/optional media dependencies and their relationships.

## Cache
Media artifacts can be reused by deterministic asset/fingerprint keys.

## Supported media contracts
The registry supports image, diagram, TTS/audio and caption asset kinds. Caption assets can be represented as derived dependencies of narration/audio.

## Important boundary
M259 defines media orchestration contracts. It does not itself generate images, synthesize TTS, create captions or upload media to external storage. Those providers plug into the registry/cache layer.
