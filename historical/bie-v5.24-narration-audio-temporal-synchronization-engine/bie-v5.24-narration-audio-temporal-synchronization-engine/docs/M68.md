# M68 — Narration, Audio & Temporal Synchronization Engine

M68 is the temporal layer connecting educational narration to visual production.

## Core principle

**Timing follows explanation, not an arbitrary global video duration.**

The reference implementation uses:

`Audio duration → scene duration → phrase timing → captions → visual cues → Remotion timeline`

## Narration

Narration is represented as explicit segments associated with scenes.

Segments may contain:
- text
- scene reference
- timing hints
- emphasis references

## Audio

Audio assets preserve:
- voice identity
- sample rate
- duration
- language
- file reference

Actual audio duration becomes a timing input.

## Word and phrase timing

Timing can be represented at word or phrase level.

This enables:
- caption synchronization
- visual cue triggers
- emphasis
- animation timing

## Visual synchronization

A visual cue can reference a phrase and inherit its timing with an optional offset.

This means an animation can begin exactly when the narration introduces the concept.

## Scene duration

Scene duration is derived from actual audio duration with configurable tail padding.

There is no requirement that every scene be 10, 20 or 30 seconds.

Long explanations can naturally produce longer scenes.

## Captions

Captions are generated from timed phrase objects and become explicit timeline objects.

## Emphasis

Narration emphasis can be represented separately so audio delivery and visual emphasis can be synchronized.

## Important boundary

M68 does not decide what is scientifically or factually correct.

It synchronizes already-approved content.

## Relationship to previous modules

M67 decides what should be visualized.

M68 decides when each visual event should occur relative to narration/audio.

M56/M57 can then compile and render the resulting timeline.

## Production implication

This architecture supports the requirement that:
- explanation determines timing
- audio determines actual duration
- animation synchronizes to spoken content
- captions remain synchronized
- no artificial time limit is imposed on lesson generation
