# M125 — Model Quality, Cost & Routing Decision Engine

M125 decides which compatible model should execute a task under explicit quality, cost, latency and reliability constraints.

## Inputs

The routing engine consumes:
- task requirements
- model profiles
- routing weights
- optional budget limits
- routing policy version

## Capability matching

A model is eligible only if it satisfies required capability and configured constraints.

Reference constraints include:
- minimum quality
- maximum cost
- maximum latency
- minimum reliability
- context-window capacity

## Scoring

Compatible models can be ranked using weighted dimensions:

```text
Quality
Cost
Latency
Reliability
   ↓
Weighted Score
   ↓
Ranked Candidates
```

This is a reference scoring mechanism, not a universal quality metric.

Production deployments can replace it with measured task-specific evaluation scores.

## Budget

A hard budget can remove models whose estimated cost exceeds the allowed threshold.

Soft budgets can instead be represented by scoring weights or a richer policy layer.

## Fallback

The selected model receives an explicit fallback chain.

```text
Primary
  ↓ failure
Fallback 1
  ↓ failure
Fallback 2
```

Fallback selection should preserve the task's minimum requirements.

## Routing audit

Each routing decision can record:
- task ID
- requirements
- selected model
- fallback chain
- policy version
- routing reason

This makes model selection explainable and integrates naturally with M116 audit records.

## Provider neutrality

The engine does not depend on a particular provider API.

Provider-specific execution remains behind M124 adapters.

## Relationship

M124 defines provider/model abstraction.

M125 chooses the best compatible model for each task.

M123 provides configuration and policy version references.

M121 executes the resulting job.

## Important boundary

The reference quality score is not proof of model quality.

Production systems should continuously evaluate actual task outcomes and feed measured performance into routing policy.
