# M255 — Production Integration Layer: Remotion Project Wiring, Asset/Audio Injection, Render Orchestration, Logs & End-to-End Lesson Pipeline

```text
M254 Render Job
      ↓
Remotion Project Wiring
      ↓
Asset + Audio Injection
      ↓
Validation
      ↓
Render Orchestrator
      ↓
Structured Logs
      ↓
End-to-End Manifest
      ↓
Release Gate
```

## Project wiring
The module defines the handoff from generated composition source into a Remotion project directory.

## Asset/audio injection
Scene asset IDs and narration/audio IDs are resolved against registries before rendering.

## Render orchestration
A deterministic run state machine tracks validation, rendering, success/failure and retry transitions.

## Logging
Render events carry run IDs, event types, messages and metadata.

## End-to-end manifest
The complete run is summarized into one manifest suitable for release QA and observability.

## Important boundary
This package defines the integration contracts and deterministic orchestration state machine. It does **not** claim to execute an actual external Remotion process in this generated ZIP. A production worker must connect the executor transition to the real CLI/API and capture its process output.

## Architecture checkpoint
The core educational-video path is now end-to-end specified:

`Source → Understanding → Pedagogy → Assessment → Scene → Remotion Code → Render → MP4 → QA`

Future work should be production hardening: real worker execution, parallel rendering, caching, asset generation, TTS, captions, observability, cost controls and large-course orchestration.
