# M74 — Evaluation, Verification & Factual Integrity Engine

M74 is the factual-integrity gate between generated educational content and release.

## Claim-centric model

Important generated statements are represented as explicit claims.

A claim can reference:
- source evidence
- concepts
- units
- claim type

## Evidence

Evidence records identify their source and support status.

The engine does not assume that semantic similarity means factual support.

## Verification

A claim is automatically marked `SUPPORTED` only when a matching source reference and explicitly supported evidence are present.

Otherwise it becomes `REVIEW_REQUIRED`.

## Numerical verification

The engine exposes explicit numeric checks with configurable tolerance.

This can be extended with:
- symbolic algebra
- equation solvers
- reference-value databases
- statistical checks

## Unit verification

Unit and dimensional checks are explicit.

Production adapters can add full dimensional-analysis systems and conversion libraries.

## Contradiction detection

Explicit contradiction pairs can block release.

Future adapters can generate candidate contradiction pairs using retrieval/NLI/LLM analysis, but the release gate should operate on validated contradiction records.

## Cross-representation consistency

The same concept can appear as:
- narration
- equation
- diagram label
- caption
- assessment answer

M74 provides a consistency gate so these representations do not silently disagree.

## Provenance

Claims retain source references and can link to derived artifacts.

This enables source → claim → output traceability.

## Domain independence

The architecture is not Physics-specific.

The same integrity layer can check:
- mathematical statements
- scientific facts
- historical claims
- economic statistics
- programming/API facts
- professional training material

The domain-specific validators can be plugged in without changing the core claim/evidence model.

## Important boundary

M74 verifies against provided evidence and explicit validators.

It does not magically establish truth where no authoritative evidence exists.

## Relationship to M72/M73

M72 stores canonical validated knowledge.

M73 tracks change impact.

M74 verifies claims and blocks unsafe release.
