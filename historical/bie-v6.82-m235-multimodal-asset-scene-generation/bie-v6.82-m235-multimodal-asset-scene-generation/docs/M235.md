# M235 — Multi-Modal Asset Planning, Visual Style Personalization, Narration/Voice Selection & Accessibility-Aware Scene Generation

```text
Lesson / Scene Requirements
          ↓
   Multi-Modal Asset Plan
          ↓
  Visual Style Personalization
          ↓
   Voice / Narration Selection
          ↓
 Accessibility Constraints
          ↓
   Scene Generation Contract
          ↓
      Scene QA Gate
```

## Asset planning
Each scene can request diagrams, text and other typed assets with semantic roles and accessibility metadata.

## Visual personalization
Learner preferences control density, contrast, motion and layout.

## Voice selection
The engine chooses an available voice compatible with the learner's requested voice, language and pacing preferences.

## Narration
Narration carries voice, language, pace and audio-description requirements.

## Accessibility-aware scene contract
Accessibility requirements travel with the scene so downstream renderers can enforce them.

## Boundary
M235 defines planning and rendering contracts. Actual image/audio/video synthesis remains the responsibility of downstream media generators.
