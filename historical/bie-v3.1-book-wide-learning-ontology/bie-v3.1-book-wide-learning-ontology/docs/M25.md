# M25 — Book-Wide Learning Ontology

M25 formalizes the user's central decomposition idea across the whole book, not just individual concepts.

## Eight learning axes

Every meaningful information unit is inspected through:

1. WHAT — definition, identity, properties, components, classification
2. WHO — actors, entities, contributors, affected parties
3. WHEN — time, chronology, sequence, temporal conditions
4. WHERE — location, spatial context, scope
5. WHY — causes, purpose, rationale, consequences
6. HOW — mechanism, process, procedure, derivation, method
7. WHICH — choices, categories, conditions, comparisons
8. HOW MUCH — quantities, measurements, magnitudes, frequencies

## Important behavior

An axis is not forced to have an answer.

If a book does not contain a meaningful WHO or WHERE answer, it is marked NOT_APPLICABLE_OR_NOT_FOUND rather than invented.

This is critical for grounded learning.

## Question generation

Each learning unit can produce axis-specific questions. These are candidates, not automatically valid exam questions. Later stages should validate them against evidence and learning objectives.

## Applications

Applications are represented separately and can be classified into daily-life or current-world contexts. Their mechanism link and evidence are preserved.

## Misconceptions

Potential misconceptions have explicit verification status. The system should not manufacture a “common misconception” merely because a model thinks it sounds plausible.

## Book-wide coverage

The ontology is intended to cover the entire book. Chapter/section-level units later aggregate into a curriculum-wide map.
