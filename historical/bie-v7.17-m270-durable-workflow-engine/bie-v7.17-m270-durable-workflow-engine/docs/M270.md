# M270 — Durable Workflow Engine

```text
Workflow Definition
       ↓
State Machine Instance
       ↓
Event / Command
       ↓
State Transition
       ↓
Persist
       ↓
 ┌─────┴─────┐
 ↓           ↓
Resume     Timeout
 ↓           ↓
Continue   Recovery / Compensation
```

## Definitions
A workflow declares states, transitions and an initial state.

## Execution
Events drive explicit state transitions. Invalid transitions are rejected.

## Durability
Workflow instances can be persisted and resumed from stored state.

## Recovery
A workflow can reconstruct state from its persisted instance and event history.

## Timeouts
Long-running states can have deadlines that produce timeout signals.

## Compensation
Executed side effects can be represented in reverse order for compensating actions.

## Boundary
M270 defines workflow semantics and persistence contracts. It does not itself provide a database, distributed timer service or transaction coordinator.
