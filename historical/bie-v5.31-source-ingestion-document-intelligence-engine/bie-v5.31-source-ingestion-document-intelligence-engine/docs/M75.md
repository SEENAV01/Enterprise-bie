# M75 — Source Ingestion & Document Intelligence Engine

M75 is the source-understanding foundation for BIE.

## Input types

The architecture supports adapters for:
- born-digital PDFs
- scanned/image PDFs
- OCR documents
- structured document formats

The core representation does not depend on a specific parser or OCR vendor.

## Canonical source representation

The canonical model preserves:
- document identity
- pages
- page dimensions
- regions
- reading order
- text blocks
- tables
- figures
- equations/formulas

## Provenance

Every extracted region/block can retain:
- document id
- page number
- region id
- bounding box
- extraction method
- confidence

This makes later claims traceable back to exact source locations.

## OCR

Scanned pages can pass through an OCR adapter.

OCR confidence is retained.

Low-confidence extraction is marked for review rather than silently treated as authoritative text.

## Layout understanding

Reading order is explicit.

This matters because a PDF page is a visual layout, not necessarily a linear text stream.

Production adapters can later add:
- columns
- headers/footers
- sidebars
- callouts
- nested sections
- lists

## Tables

Tables are represented structurally rather than flattening them into prose.

This allows later reasoning over rows, columns, headers and values.

## Figures

Figures are preserved as first-class source objects with references and captions.

They can later feed visual understanding and educational reconstruction.

## Formulas

Equations are first-class objects.

The architecture supports multiple representations such as LaTeX/text plus extraction confidence.

Production adapters can add equation OCR and symbolic normalization.

## Important boundary

M75 extracts and structures source material.

It does not decide what the material means pedagogically. That remains downstream in the knowledge/reasoning layers.

Likewise, extraction confidence is not factual truth.

## Relationship to earlier modules

M75 feeds M53 with a high-fidelity canonical source.

M74 can use M75 provenance for claim verification.

M72 can store validated source-derived knowledge.

M73 can use source-region identity for precise change impact.

## Domain independence

This engine is not Physics-specific.

The same representation can ingest textbooks, manuals, legal/technical documents, programming books, course PDFs and other structured sources.
