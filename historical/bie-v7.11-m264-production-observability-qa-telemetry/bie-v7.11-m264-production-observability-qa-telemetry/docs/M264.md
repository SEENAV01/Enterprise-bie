# M264 — Production Observability & QA Telemetry

```text
BIE Runtime
   ↓
Structured Events
   ├── Metrics
   ├── Traces
   ├── Failure Analytics
   ├── Lesson / Scene Summaries
   └── Audit Trail
          ↓
   Observability Gate
```

## Events
All important runtime transitions use normalized event records with timestamp, run ID, type, level and payload.

## Metrics
Render starts, successes, failures and retries are aggregated into operational metrics including success rate.

## Tracing
Trace/span contracts connect course, lesson, scene and worker operations.

## Failure analytics
Failure codes are aggregated to identify recurring production problems.

## Scope summaries
Telemetry can be grouped by lesson or scene for localized diagnostics.

## Audit trail
Render and repair actions record actor, target, result and optional reason.

## Boundary
M264 defines telemetry contracts and aggregation. Storage, dashboards and external observability backends can consume these records without changing the BIE core.
