# M243 — Pedagogical Learning Path Optimization, Concept Sequencing, Cognitive Load Control & Lesson Granularity

```text
Prerequisite Graph + Lesson Units
              ↓
       Sequence Optimization
              ↓
       Cognitive Load Check
              ↓
      Lesson Granularity Check
              ↓
        Learning Path QA
              ↓
        Optimization Gate
```

## Sequence optimization
The path preserves prerequisite dependencies while ordering ready concepts by priority.

## Cognitive load
Each unit can declare intrinsic, extraneous and germane load estimates. Configurable thresholds reject overloaded units.

## Granularity
Units are checked for duration and number of concepts to avoid excessively small or overly dense lessons.

## Pedagogical path
The resulting path combines dependency order with load and granularity checks.

## Boundary
M243 provides explicit heuristics and constraints, not a validated cognitive-science model. Production systems can replace the heuristics with empirically calibrated learner models and assessment feedback.
