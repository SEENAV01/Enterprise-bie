# M27 — Curriculum / Lesson Planner

M27 is the first layer that converts book understanding into an explicit teaching plan.

## Inputs

The planner consumes:
- learning objective
- knowledge graph
- dependency/prerequisite graph
- evidence mappings
- application candidates

## Sequence

The sequence is dependency-driven. A target lesson begins with the prerequisite chain required to reach the target.

The planner is not duration-driven. Video duration is determined later from the amount of explanation, presentation and synchronized audio.

## Lesson blocks

The baseline planner can select:
- orientation
- prerequisite review
- definition
- intuition
- mechanism
- derivation
- worked example
- application
- comparison
- misconception
- checkpoint
- recap
- transfer

Not every lesson needs every block. Objective type controls which blocks are appropriate.

## Grounding

Blocks should retain evidence IDs. The validation layer flags non-orientation blocks that have no evidence mapping.

## Visual intent

Each block declares a high-level visual intent. This is NOT the final Remotion scene. It is an instruction to the future scene planner.

## Timing

The planner deliberately does not assign fixed durations. Later audio/script generation determines narration length and animation timing.

This follows the project's requirement that timing and animation should be based on proper explanation/presentation and audio synchronization rather than an arbitrary time limit.

## Important distinction

M27 decides **what should be taught and in what pedagogical order**.

It does not yet decide exact camera movements, SVG construction, animation curves, voice timing or Remotion implementation.
