# M23 — Grounded Evidence Retrieval + Book Understanding

M23 adds the retrieval/reasoning boundary between multimodal ingestion and BIE.

## Retrieval

A query is matched against page-level evidence and ranked.
The included implementation is a deterministic baseline; production should replace/augment it with embedding and multimodal retrieval.

## Cross-page context

Retrieved evidence expands to nearby pages so explanations that span page boundaries are not truncated.

## Evidence ranking

Ranking can incorporate:
- semantic relevance
- modality
- provenance
- page/context relationships
- later: figure-caption links, heading hierarchy, chapter position and confidence

## Grounding policy

The downstream model receives a grounded packet with:
- query
- ranked evidence
- context window
- provenance
- explicit policy against unsupported claims

Source terminology should be preserved. If evidence does not support a claim, it should be flagged rather than silently filled with outside knowledge.

## Contradictions

Potential conflicts are surfaced for review instead of being silently reconciled.

## Production retrieval

The next implementation should use hybrid retrieval:
BM25/lexical + dense embeddings + multimodal retrieval + metadata filtering + reranking.

For figures/tables/equations, the retriever should support both textual descriptions and the original asset representation.
