# M82 — Asset, Visual Style & Reusable Component Intelligence Engine

M82 creates a consistent visual production system across an entire lesson or course.

## Assets

Assets are first-class records.

Supported categories include:
- images
- icons
- illustrations
- audio/video references
- fonts
- models/textures
- diagram components
- equation assets

Assets can retain semantic tags, source references and license information.

## Semantic selection

Assets can be selected by semantic compatibility rather than filename or arbitrary similarity.

Production systems can extend this with:
- embedding search
- visual similarity
- domain constraints
- resolution/format requirements
- license constraints

## Style system

A canonical style system stores reusable visual tokens and component styles.

This prevents every generated scene from inventing a new visual language.

## Reusable components

Components have semantic contracts.

Examples:
- charge particle
- vector arrow
- coordinate axis
- equation block
- timeline node
- character
- graph component

Instances can reuse the same component with controlled properties.

## Templates

Reusable templates support common educational structures:
- title
- definition
- comparison
- process
- diagram
- equation
- timeline
- chart
- quiz
- simulation
- summary

## Visual drift

Long courses can suffer from gradual style inconsistency.

M82 provides drift detection against canonical style/component definitions.

Production systems can enforce strict or tolerant drift policies.

## Provenance and licensing

Generated or selected assets retain source/creation/license metadata.

This is important for production release and course-scale asset reuse.

## Renderer independence

M82 does not render assets itself.

It supplies the visual system consumed by scene compilers and renderers.

## Domain independence

The architecture is not Physics-specific.

The same component/style system can support:
- science diagrams
- mathematics
- programming
- history timelines
- business charts
- technical training
