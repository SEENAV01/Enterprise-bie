# M46 — Intelligent Scene Orchestrator

M46 controls how multiple visual components work together inside a scene.

M43 defines visual intent.
M45 provides visual components.
M46 decides how those components are composed for comprehension.

## Core responsibilities

M46 manages:

- spatial layout
- object hierarchy
- collision avoidance
- visual focus
- simultaneous animation
- cognitive-load heuristics
- semantic priority
- scene validation

## Spatial intelligence

Objects receive explicit rectangles and are placed into the available canvas.

The system detects collisions rather than silently allowing overlap.

A production version can replace the baseline layout algorithm with constraint solving, graph layout, force-directed placement, mathematical typesetting constraints, or learned layout policies.

## Visual hierarchy

Objects have semantic roles:

PRIMARY
SECONDARY
SUPPORTING
DECORATIVE

Primary educational content wins spatial and visual priority.

Decorative elements are deliberately down-ranked.

## Focus management

At any moment the system can identify active objects.

Active objects:
- full opacity
- emphasis

Supporting inactive objects:
- reduced visual weight

Decorative inactive objects:
- strongly reduced weight

This implements attention guidance without deleting contextual information.

## Animation coordination

Multiple animations are analyzed for overlap.

If too many animations are simultaneously active, the orchestrator recommends sequencing.

The objective is not maximum motion. The objective is comprehension.

## Cognitive load

M46 includes a heuristic estimate using:
- number of objects
- simultaneous animations
- text volume

This is a heuristic, not a psychological measurement.

Later versions can replace it with empirical learner data.

## Critical design principle

The orchestrator may simplify or sequence a visual presentation, but it must not remove information that is pedagogically required without recording the decision.

A future production implementation should therefore support:
- required objects
- optional objects
- simplification alternatives
- fallback layouts
