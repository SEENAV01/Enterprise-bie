# M17 — Remotion Component Registry

M17 makes the Scene DSL renderable by a reusable Remotion component registry.

## Boundary

Scene DSL → Registry → React/Remotion → Composition → MP4

The AI does not generate arbitrary React for each scene. It selects/configures a known renderer component.

## Registry

Current component types:
- DefinitionScene
- ProcessScene
- EquationScene
- DiagramScene
- ChartScene
- TableScene
- ApplicationScene
- WorkedExampleScene
- CheckpointScene
- RecapScene

Aliases allow causal explanations, comparisons, derivations and process scenes to reuse stable primitives.

## Timeline

Each Scene DSL duration is converted to frames using the declared FPS.
The manifest supplies the total composition duration.

## Important production rule

The current components are intentionally a minimal renderer shell. They establish the contract and deterministic routing. The next renderer iteration should replace the shell visuals with production-quality components: animated diagrams, LaTeX equations, charts, tables, camera choreography, asset loading, captions and TTS-synced timing.

## Why this architecture scales

A single renderer component can serve thousands of scenes. Improvements to the component automatically improve every generated course instead of requiring the LLM to rewrite code.
