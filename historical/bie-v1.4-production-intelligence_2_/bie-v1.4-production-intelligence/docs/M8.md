# M8 — Production Intelligence

M8 is the control layer between educational intelligence and rendering.

## 1. Quality control
The system checks:
- source provenance
- missing purpose
- dependency integrity
- render readiness
- explicit review states

Critical errors block final rendering.

## 2. No silent corrections
If the book appears ambiguous or inconsistent, the system records a REVIEW state.
It does not silently substitute model knowledge.

## 3. Dependency graph
The lesson is represented as a directed graph, not only a linear video.
This enables:
- prerequisite remediation
- alternate lesson paths
- skipped mastered material
- targeted revision

## 4. Adaptive learning
Example routing:
- >= 85%: advance
- 60–84%: remediate with another visual explanation
- < 60%: reteach prerequisite, then retry

These thresholds are configuration defaults, not claims about a universal pedagogy.

## 5. Render orchestration
Scene jobs are generated from the production manifest.
Final MP4 is blocked until critical QC errors are resolved.

## 6. Architecture
Book -> BIE -> Content Graph -> Learning Graph -> Scene DSL -> Production Manifest
-> QC -> Adaptive Runtime -> Remotion -> Audio/Captions -> MP4

This makes the system scalable beyond a single lesson.
