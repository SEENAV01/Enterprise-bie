# M211 — Automated Video Rendering & QA Integration

M211 is the execution boundary between the video composition plan and a validated video artifact:

```text
Video Composition
      ↓
 Render Job
      ↓
Renderer Adapter
      ↓
Rendered Artifact
      ↓
Automated QA
      ↓
QA Report
      ↓
Output Manifest
      ↓
Verified Video Artifact
```

## Render orchestration

A render job binds a composition to a render profile and output target.

## Renderer adapter

The adapter contract allows engines such as Remotion to execute the composition without coupling the BIE core to one renderer implementation.

## Render result

The result records status, output, duration, frame count, file size and checksum.

## Automated QA

The initial QA contract covers file existence, duration, frame count, resolution, FPS, audio presence/synchronization, caption synchronization, scene coverage, black/freeze frames, corruption and checksum.

## Retry

Transient failures can be retried according to a bounded retry policy.

## Output manifest

Successful artifacts are registered in a manifest with format and checksum.

## Provenance and verification

The rendered artifact remains traceable to composition and render profile and must pass the final verification gate.

## Boundary

M211 defines orchestration and QA contracts. Actual rendering and media inspection are delegated to the selected renderer/worker implementation.
