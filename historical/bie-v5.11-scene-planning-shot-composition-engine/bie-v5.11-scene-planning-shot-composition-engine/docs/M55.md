# M55 — Scene Planning & Shot Composition Engine

M55 converts learning objectives, narration timing, semantic visuals, assets and style rules into a renderer-independent shot plan.

## Core purpose

M55 answers:

**What should be on screen at this exact point in the explanation?**

It creates semantic shots rather than arbitrary time slices.

## Inputs

M55 consumes:
- learning objectives
- narration segments and timing
- scientific/mathematical visual objects
- asset references
- style bible
- visual grammar
- optional transitions

## Shot

A shot contains:
- purpose
- narration segment references
- visual references
- asset references
- composition reference
- camera plan
- timing source

## Composition

Composition can define:
- layout
- primary focus
- secondary focus
- background
- staging
- camera relationship

The focus hierarchy prevents every object from competing for attention.

## Camera

Camera movement is represented semantically.

A camera move should have a reason such as:
- focus on the newly introduced concept
- reveal a relationship
- follow a physical process
- establish a new spatial context

The architecture does not force every shot to move.

## Transitions

Transitions require a semantic reason.

Examples:
- CUT for a conceptual jump
- CONTINUE when the same state evolves
- MATCH_STATE when two views represent the same underlying state
- MORPH when a meaningful transformation occurs

## Timing

Narration is the primary temporal reference.

There is no arbitrary fixed shot duration.

A shot can span one or more narration segments when that is pedagogically appropriate.

## Renderer independence

M55 does not generate Remotion code directly.

It produces a production plan that a renderer can consume.

This separation is important:

`Planning → Rendering`

rather than:

`LLM → random JSX`

## Density control

A scene should not show every available asset simultaneously.

The planner should prioritize:
1. what is being explained now
2. what is necessary for context
3. what can remain visually quiet

## Relationship to previous modules

M50 defines what the learner should achieve.

M51 defines the narration timeline.

M52/M53 define scientifically meaningful and valid visual states.

M54 defines consistent visual language and assets.

M55 combines these into a shot-by-shot production blueprint.
