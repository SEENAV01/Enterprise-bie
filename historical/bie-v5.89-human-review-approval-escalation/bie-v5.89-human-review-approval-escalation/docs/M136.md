# M136 — Human-in-the-Loop Review, Approval & Escalation Layer

M136 provides a governed human-review path for outputs that automated evaluation cannot safely release.

## Review queue

Review items enter an explicit queue with:
- priority
- evidence
- required reviewer role
- review SLA

Queue ordering is priority-aware.

## Reviewer assignment

Reviewers have explicit roles and capacity.

An item requiring a role can only be assigned to an eligible active reviewer.

## Evidence packet

A reviewer receives a structured evidence packet containing:
- artifact
- automated evaluations
- deterministic checks
- provenance references

This reduces the need for reviewers to reconstruct system history manually.

## Structured decisions

Allowed decisions are:

```text
APPROVE
REJECT
ESCALATE
REQUEST_CHANGES
```

Every decision carries a rationale and evidence references.

## Escalation

Uncertain or high-impact cases can be escalated to a target role.

## Overrides

An override does not silently replace an existing decision.

```text
Original Decision
       ↓
Override Request
       ↓
Reason
       ↓
Explicit Approval
       ↓
Override Approved
```

## Review SLA

Review requests can have an SLA and can be marked breached when elapsed time exceeds the configured limit.

## Release gate

Human review is composed with automated evaluation:

```text
Automated Gate ✓
       +
Human APPROVE
       ↓
Release Eligible
```

A human approval does not bypass a failed automated gate in this reference model.

## Audit

Review decisions and evidence references can be recorded as audit events.

## Relationship

M135 determines automated quality.

M136 provides human judgment when automation should not make the final decision alone.

M130 provides durable workflow recovery around review states.

M133 governs review policy and thresholds.

## Important boundary

Reviewer identity, authentication and authorization remain governed by M132. The reference layer models review decisions and routing; production systems require secure reviewer authentication, workload balancing, notifications and durable audit storage.
