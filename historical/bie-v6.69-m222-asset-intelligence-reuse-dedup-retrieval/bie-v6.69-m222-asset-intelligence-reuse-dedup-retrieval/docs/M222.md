# M222 — Asset Intelligence, Reusable Asset Library, Asset Deduplication & Semantic Asset Retrieval

```text
Lesson Requirement
       ↓
Semantic Asset Query
       ↓
Asset Index
  ├── Compatibility Filter
  ├── Relevance Ranking
  └── Deduplication
       ↓
Reuse Existing Asset
       │
       └── if no suitable asset → Generate New
```

## Asset library
Assets are indexed by stable IDs and retain type, URI, metadata, tags, checksum and version.

## Semantic retrieval
Queries are matched against tags, subject metadata and asset type.

## Deduplication
Checksums identify identical asset content so duplicate registrations can resolve to a canonical asset ID.

## Reuse planning
The engine chooses REUSE when a suitable candidate is found, otherwise GENERATE_NEW.

## Compatibility
Asset type and metadata requirements can constrain candidate selection.

## Versioning
Assets have explicit versions and stable version references.

## Boundary
M222 defines the asset-intelligence contracts. Production embeddings/vector search, object storage, CDN and perceptual-image/video hashing can replace the simple reference implementations.
