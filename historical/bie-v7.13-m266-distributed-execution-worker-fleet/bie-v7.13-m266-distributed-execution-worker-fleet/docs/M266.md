# M266 — Distributed Execution & Worker Fleet

```text
Control Plane
     ↓
 Job Queue
     ↓
Capability Scheduler
     ↓
Worker Fleet
 ├── Render
 ├── Media
 ├── TTS
 └── QA
     ↓
Lease + Heartbeat
     ↓
Result / Failure
     ↓
Requeue or Complete
```

## Worker registry
Workers advertise capabilities and capacity.

## Scheduling
Jobs are matched only to healthy workers with the required capability and available capacity.

## Leases
A job lease identifies ownership and expiry. Expired leases can trigger requeue.

## Health
Heartbeats keep workers healthy; unhealthy workers can be isolated from scheduling.

## Fault recovery
Expired work is requeued with an incremented attempt counter.

## Autoscaling
Queue depth and worker capacity produce a desired fleet size and SCALE_OUT/SCALE_IN/HOLD action.

## Boundary
M266 defines distributed execution contracts. It does not provision cloud instances or implement a specific queue broker; infrastructure adapters can consume these contracts.
