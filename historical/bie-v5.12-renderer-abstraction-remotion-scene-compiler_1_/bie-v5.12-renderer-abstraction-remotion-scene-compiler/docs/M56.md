# M56 — Renderer Abstraction & Remotion Scene Compiler

M56 is the boundary between educational/visual planning and rendering technology.

## Architecture

`Educational reasoning → M55 shot plan → Renderer IR → Renderer adapter → render`

The renderer IR contains canvas settings, duration, layers, components, animation keyframes, audio, captions and transitions.

Remotion is an adapter, not the knowledge layer.

## Reusable component types

Text, equations, images, SVG, shapes, graphs, vector fields, particle systems, groups, captions and audio can be represented.

## Timing

M51 supplies narration timing and M55 supplies shot timing. M56 makes that timing frame-addressable. No fixed runtime is imposed.

## Determinism

The same validated inputs should produce the same scene specification, supporting caching, debugging and reproducible renders.

## Boundary

M56 does not decide what to teach or what is scientifically true. It compiles an already-planned scene into a renderer-ready structure.
