# M49 — Curriculum Reconciliation Engine

M49 merges source-grounded knowledge from M47 with approved expansions from M48 into a coherent learning graph.

## Main problem

Source material and higher-order enrichment are not automatically a curriculum.

They may contain:
- duplicates
- missing prerequisites
- concepts at different difficulty levels
- optional enrichment
- conflicting statements
- concepts that should be taught in a different order

M49 reconciles these into an explicit learning structure.

## Merge

Nodes are merged by stable concept ID while preserving origin metadata.

The system never erases whether a concept came from the source or an expansion.

## Prerequisites

Prerequisite edges create a directed learning graph.

A topological ordering produces a candidate teaching order.

Cycles are quality-gate errors because they indicate unresolved curriculum dependencies.

## Contradictions

Potential contradictions are flagged.

M49 does not silently choose one statement over another.

Resolution requires:
- evidence comparison
- scope/context analysis
- source authority
- explicit editorial decision

This prevents accidental loss of nuance.

## Learner level

The same knowledge graph can support different depth levels.

A foundation learner may receive the core concept while advanced learners can receive:
- deeper theory
- mathematical formalism
- limitations
- modern context
- cross-domain connections

## Core vs Deep Dive

Every concept receives an explicit delivery classification.

CORE:
Required for the intended learning path.

DEEP_DIVE:
Useful but not necessary for the core learning objective.

This enables one knowledge graph to generate multiple course depths.

## Important principle

M49 does not shorten the content merely to hit a fixed video duration.

Lesson timing is determined downstream by the explanation required for comprehension, narration and synchronized animation.
