# M152 — Security Policy Enforcement Layer

M152 defines the security decision boundary for BIE APIs, workflows, workers, artifacts and internal services.

## Identity

Identity records carry:
- subject ID
- tenant ID
- identity type
- roles
- claims

Service identities are explicitly represented as `SERVICE`.

## Authentication context

Authentication produces a context that can be propagated into downstream authorization decisions.

The reference model records authentication method and time.

## Authorization

An authorization request contains:

```text
Subject
Tenant
Action
Resource
Context
```

The decision is either ALLOW or DENY.

## RBAC

Roles contain permissions.

A permission identifies:
- action
- resource
- effect
- optional conditions

The reference implementation supports an RBAC foundation.

## Deny by default

The security policy default effect is DENY.

If no explicit permission matches, authorization returns:

```text
DENY
NO_EXPLICIT_PERMISSION
```

## Tenant isolation

Subject and resource tenant IDs are compared before permission approval.

A mismatch produces a tenant-isolation denial.

## Policy versioning

Security policies carry an explicit version so authorization decisions can be tied to the policy revision that produced them.

## Audit

Authorization decisions can record:
- decision ID
- subject
- tenant
- action
- resource
- decision
- policy version
- timestamp
- reason

## Privileged operations

Sensitive operations can require:
- step-up authentication
- audit recording

These requirements are represented explicitly in the operation contract.

## Relationship

```text
M145 API
   ↓
M152 Identity
   ↓
Authentication Context
   ↓
Authorization Policy
   ↓
Tenant Boundary
   ↓
ALLOW / DENY
   ↓
Audit
```

M146 governs dynamic policy configuration.

M150 carries diagnostic/correlation context.

M148 can provide service ownership/coordination.

## Important boundary

The reference implementation does not implement cryptographic token verification, an identity provider, OAuth/OIDC, mTLS, a policy engine, key management or production IAM. Those infrastructure components must integrate with these contracts.
