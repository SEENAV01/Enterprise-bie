# M203 — Multimodal Understanding & Evidence Extraction Integration

M203 implements the next part of the canonical BIE spine:

```text
SOURCE
  ↓
MULTIMODAL UNDERSTANDING
  ↓
EVIDENCE
  ↓
KNOWLEDGE
```

## Supported source modalities

The canonical boundary recognizes:

- TEXT
- IMAGE
- TABLE
- EQUATION
- LAYOUT

## Layout

Layout regions preserve page identity, bounding boxes, reading order and optional parent relationships.

## OCR and layout-aware extraction

Extraction records can indicate whether OCR and layout-aware processing were used and retain a confidence value.

## Structured visual objects

Figures, tables and equations receive explicit structured-object records. Their implementation remains provider/parser agnostic.

## Cross-modal evidence

M203 permits evidence to bind multiple modality records and permits explicit relationships between them. This is important for educational material where a paragraph and diagram/table/equation jointly establish a concept.

## Provenance and verification

Multimodal evidence remains traceable to source and source records and must pass an explicit verification gate.

## Quality gate

```text
source
→ layout
→ text/image records
→ OCR/layout extraction
→ structured object
→ cross-modal evidence
→ provenance
→ verification PASS
```

## Boundary

M203 does not hard-code a particular PDF parser, OCR engine, vision model, table extractor or equation recognizer. Those adapters will connect to this canonical boundary.
