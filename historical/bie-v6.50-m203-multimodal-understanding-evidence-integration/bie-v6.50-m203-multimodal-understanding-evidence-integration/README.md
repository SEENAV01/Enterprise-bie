# BIE v6.50 — M203 Multimodal Understanding & Evidence Extraction Integration

M203 extends the M202 Source-to-Knowledge boundary with multimodal source understanding: text, images, layout regions, OCR/layout-aware extraction, structured figures/tables/equations, cross-modal links, evidence, provenance and verification.

This is an integration/reference layer. It does not claim to implement a specific OCR, vision model, PDF parser or external multimodal provider.
