# M58 — Long-Form Timeline & Audio Synchronization Engine

M58 is the master temporal layer for educational video generation.

## Core principle

**Narration is the primary temporal anchor.**

The video does not have an arbitrary fixed runtime.

Instead:

`Explanation → narration duration → visual timing → animation timing → final duration`

This directly supports long lessons and complete courses.

## Master timeline

The timeline can contain:
- narration
- visual beats
- captions
- audio clips
- music
- pauses
- optional word timing
- optional phoneme timing

All are frame-addressable.

## Visual synchronization

A visual beat references a narration segment and a frame range.

Examples:
- reveal a definition when the definition is spoken
- highlight an equation when it is explained
- animate a process while the corresponding mechanism is described
- hold the final result while the conclusion is spoken

## Emphasis

Narration can declare emphasis phrases.

Those can drive:
- visual emphasis
- camera focus
- caption emphasis
- animation intensity

The exact visual treatment remains upstream in the scene/style system.

## Captions

Captions use the same master timeline as narration and visuals.

Word-level timing is supported when available.

## Phoneme timing

Phoneme events can optionally be attached to words.

This enables future:
- lip synchronization
- pronunciation-aware highlighting
- fine-grained mouth/character animation

Phoneme timing is optional; the system does not require it for ordinary narration.

## Music and SFX

Music/SFX clips occupy explicit timeline lanes.

Music ducking can reduce the music level during narration.

## Adaptive duration

If the explanation becomes longer, the timeline grows.

If an animation needs a little more time than the narration, the planner can extend the scene deliberately.

There is no global artificial time limit.

## Long-form operation

The same timeline model can represent:
- one scene
- one lesson
- an entire chapter
- an entire course

The production system can later partition a course timeline into renderable scene/chapter units while preserving absolute timing references.

## Quality gate

The compiler checks basic synchronization integrity.

For example, a visual beat referring to a narration segment but occurring outside that segment is flagged.

The system should never silently claim synchronization when timing data is invalid.

## Relationship to previous modules

M58 creates the shared temporal contract connecting narration, visuals, captions and audio across long-form content.
