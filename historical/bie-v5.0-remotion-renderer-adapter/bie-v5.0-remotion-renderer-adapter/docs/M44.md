# M44 — Remotion Renderer Adapter

M44 is the renderer boundary.

Everything before M44 is concerned with knowledge, pedagogy, narrative, timing and renderer-neutral visual representation.

M44 converts that stable representation into a Remotion-oriented specification.

## Responsibilities

M44 handles:
- component registry
- second → frame conversion
- scene sequences
- composition metadata
- audio attachment
- lifecycle-to-renderer bindings
- deterministic rendering policy
- render-spec validation

## What M44 must NOT do

M44 must not:
- rewrite the pedagogical order
- shorten explanations to fit a preset duration
- invent knowledge
- change narration
- decide whether a concept is important
- replace the timeline with arbitrary animation timing

Those decisions belong upstream.

## Component registry

Knowledge primitives map to reusable renderer components.

Examples:
TEXT → KnowledgeText
EQUATION → Equation
DIAGRAM → Diagram
PARTICLE → ParticleSystem
HIGHLIGHT → Highlight

The registry is intentionally centralized so components can be upgraded without changing the knowledge pipeline.

## Audio

Audio is attached to the composition timeline.

Because M42 already established actual audio timing, M44 consumes those timings rather than estimating them.

## Determinism

Programmatic educational video generation needs reproducibility.

The adapter therefore requires:
- stable object IDs
- seeded randomness
- immutable source specification
- no runtime content generation

Given the same inputs, the render should reproduce the same result.

## Quality gate

Before rendering, validate:
- FPS
- duration
- frame count
- scene presence
- composition/timeline consistency

## Current status

M44 establishes the renderer boundary and a minimal Remotion adapter template.

It intentionally does not pretend that the entire production-grade component library is finished.

## Next

M45 should build the Production Visual Component System: reusable, pedagogically-aware Remotion components for equations, diagrams, graphs, processes, particles, labels, highlights, camera motion, transitions, text and synchronized audio cues, with consistent APIs and performance controls.
