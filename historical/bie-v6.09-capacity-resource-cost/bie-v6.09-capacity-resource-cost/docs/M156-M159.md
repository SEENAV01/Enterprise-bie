# Capacity, Resource Governance & Cost Controls

This layer governs finite compute, storage, request and concurrency resources and attaches cost accounting to resource consumption.

## Resource utilization

Resources have a declared capacity and current usage.

```text
utilization = current / capacity
```

## Quotas

Quotas bound resource consumption for a tenant or scope over an optional period.

## Rate limits

Rate limits constrain request frequency and can include burst capacity.

## Concurrency

Concurrency limits prevent unbounded simultaneous work and can define a queue allowance.

## Autoscaling

Autoscaling policies define:
- minimum instances
- maximum instances
- target utilization

The reference helper demonstrates a simple scale-up/scale-down policy. Production autoscaling should use platform-native signals and stabilization rules.

## Resource budgets

Budgets express expected limits for compute, storage and request units.

## Cost attribution

Cost records separate:
- compute
- storage
- network
- request

and expose a total cost for the service and period.

## Governance

A resource policy groups quotas, rate limits, concurrency controls and budgets under one service-level contract.

## Relationship

```text
Workload
  ↓
Resource Consumption
  ↓
Quota / Rate / Concurrency
  ↓
Autoscaling
  ↓
Resource Budget
  ↓
Cost Attribution
```

This layer complements M151 reliability and M156 recovery.

## Boundary

The reference implementation does not connect to a cloud billing API, scheduler, container orchestrator or production autoscaler.
