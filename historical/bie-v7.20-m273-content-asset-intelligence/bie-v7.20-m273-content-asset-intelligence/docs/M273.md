# M273 — Content & Asset Intelligence Layer

```text
Artifact Manager
      ↓
 Asset Metadata
      ↓
Classification + Tags
      ↓
Quality / Perceptual Fingerprint
      ↓
Embedding / Semantic Index
      ↓
Duplicate + Near-Duplicate Detection
      ↓
Suitability Score
      ↓
Ranked Asset Selection
```

## Metadata
Assets carry normalized media type and optional dimensions, duration and source metadata.

## Classification
The layer maps media types to semantic classes and derives lightweight tags.

## Fingerprints
Normalized features produce deterministic fingerprints. Similarity provides a near-duplicate contract.

## Embeddings
Embedding records carry model identity and dimensions and can be queried by vector similarity.

## Suitability
Requirements such as media type and minimum dimensions produce a bounded 0–1 suitability score and ranked candidates.

## Boundary
M273 defines intelligence and indexing contracts. It does not prescribe a specific embedding model, vector database, computer-vision model or production search engine.
