# M87 — Misconception, Diagnostic Reasoning & Remediation Planner

M87 closes the diagnostic side of the learning loop.

## Diagnostic categories

The planner distinguishes:
- concept gap
- prerequisite gap
- misconception
- procedural error
- representation gap
- possible careless error
- unknown

This prevents every incorrect answer from being labeled a misconception.

## Evidence-based diagnosis

A diagnosis can reference the assessment evidence that supports it.

Multiple hypotheses are allowed.

For example, a wrong numerical answer might be consistent with:
- missing prerequisite
- unit conversion error
- conceptual misunderstanding

The system can retain these hypotheses with confidence rather than forcing an unjustified single conclusion.

## Prerequisite reasoning

Prerequisite concepts can be ranked.

If a learner repeatedly fails a concept because a prerequisite is weak, remediation can target the prerequisite rather than repeatedly explaining the advanced concept.

## Targeted remediation

Strategies include:
- re-explanation
- concrete example
- counterexample
- visual representation
- guided practice
- prerequisite review
- misconception contrast
- scaffolded problem
- reteach and retry

The remediation target is explicit.

## Adaptation

An adaptation plan connects diagnosis to the next learning action.

Examples:
- misconception detected → contrast misconception with correct model
- prerequisite gap detected → review prerequisite
- representation gap detected → switch representation modality
- possible careless error → retry with low-friction feedback

## Reassessment

A remediation plan should specify how learning will be checked again.

The reassessment can target:
- same objective
- same diagnosis
- controlled difficulty change
- a particular evidence goal

## Important architectural principle

M87 does not claim certainty when evidence is weak.

It can retain:
`hypothesis + evidence + confidence`

This is safer and more useful than pretending that one wrong answer reveals the learner's exact mental model.

## Relationship

M86 produces assessment evidence.

M87 diagnoses the likely reason for performance.

M87 selects remediation and reassessment.

M78 receives the resulting evidence and updates mastery/adaptation.

## Core loop

`Teach → Interact → Assess → Diagnose → Remediate → Reassess → Adapt`
