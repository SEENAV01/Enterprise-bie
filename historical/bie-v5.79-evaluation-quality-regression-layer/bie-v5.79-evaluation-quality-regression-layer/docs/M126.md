# M126 — Evaluation, Quality Measurement & Regression Layer

M126 measures actual model/task performance instead of relying only on static model metadata.

## Evaluation loop

```text
Model
  ↓
Golden Dataset
  ↓
Generate / Execute
  ↓
Task-specific Rubric
  ↓
Score
  ↓
Quality Gate
```

## Golden datasets

A benchmark suite contains versioned cases with:
- case ID
- input
- expected result
- task type
- metadata

Golden datasets should be curated and versioned.

## Rubrics

A rubric defines measurable dimensions and a threshold.

Examples of dimensions can include:
- factual correctness
- structural compliance
- visual similarity
- narration quality
- code correctness

The actual dimensions should be task-specific.

## Automated evaluation

Each case can produce dimension scores.

The reference implementation combines them using weighted scoring and compares the result against an explicit threshold.

## Regression detection

A current evaluation can be compared with a baseline.

```text
Baseline Score
      ↓
Current Score
      ↓
Delta
      ↓
Regression?
```

Regression tolerances can be absolute and relative.

## Model comparison

Multiple models can be evaluated against the same suite and ranked by measured score.

Cost, latency and reliability can also be retained alongside the quality score.

This allows M125 routing to eventually use measured evidence.

## Evaluation provenance

An evaluation record can reference:
- model
- dataset + version
- rubric + version
- configuration reference

This makes quality claims reproducible and auditable.

## Promotion gate

An evaluation failure blocks promotion.

A detected regression can also block promotion.

## Relationship

M125 chooses models.

M126 measures how those models actually perform.

M115 can consume these quality gates.

M123 provides configuration references.

M116 can record evaluation and promotion decisions.

## Important boundary

Automated evaluation is not automatically ground truth.

For subjective or high-impact outputs, human review, calibrated evaluators or multiple evaluation methods may be required.
