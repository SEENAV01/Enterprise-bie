# M254 — Render Executor Integration, Remotion Build Validation, MP4 Export Pipeline & Render Failure Recovery

```text
M253 Render Job
      ↓
Build Environment Validation
      ↓
Project Build
      ↓
Render Request
      ↓
Remotion Executor Adapter
      ↓
MP4 Artifact
      ↓
Render QA
      ↓
Release Gate
      ↘
       Failure Classification → Retry / Fail Fast
```

## Execution boundary
M254 turns the render-job contract into an executor request and defines the output-artifact contract.

## Build validation
The pipeline validates that required Node/Remotion environment information exists before release.

## MP4 artifact
The artifact manifest records output path, MP4 container, H.264 codec, FPS and duration.

## Failure recovery
Known transient failures are classified as retryable; non-transient failures fail fast. Retry limits are explicit.

## QA and release
The release gate blocks publication unless build, render, artifact and output-path checks all pass.

## Important implementation note
The executor in this package is an adapter/stub contract. It does **not** actually invoke a local Remotion CLI in this generated package. Production execution must connect the adapter to the real Remotion project/worker.

## Architecture checkpoint
M253 + M254 now cover the complete contract:

`Scene → Remotion Code → Render Job → Render Executor → MP4 → QA Gate`

The remaining work should primarily be integration, real rendering, observability, performance, asset/audio generation and production hardening.
