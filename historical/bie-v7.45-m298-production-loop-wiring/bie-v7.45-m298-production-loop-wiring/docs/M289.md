# M289 — Real MP4 Render Execution

M289 executes the generated Remotion project instead of merely generating source code.

```text
Remotion Project
      ↓
Node / npx
      ↓
Remotion CLI
      ↓
MP4
      ↓
File existence validation
      ↓
QA Gate
```

## Implemented

- actual Remotion CLI invocation
- project-local working directory
- MP4 output path
- render timeout handling
- explicit missing-npx blocked state
- explicit render-failure state
- output-file validation
- final QA integration
- tests + contract

## Important boundary

M289 does not fake a successful render.

If the runtime lacks Node/npx, dependencies are missing, or Remotion fails, the artifact records the exact blocked/failed state and QA remains failed.

This is intentional because a nonexistent or invalid MP4 must never be presented as a finished product.
