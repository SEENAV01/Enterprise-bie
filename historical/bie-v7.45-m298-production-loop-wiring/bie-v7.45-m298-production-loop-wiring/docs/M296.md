# M296 — Actual Automatic Re-render + Regression Decision

M296 closes the execution gap left by M295.

```text
Repair Candidate
      ↓
Remotion Regeneration
      ↓
Actual Second MP4 Render
      ↓
After-render QA
      ↓
Before ↔ After Regression
      ↓
ACCEPT / REJECT / REVIEW
```

The implementation invokes declared project commands and verifies the resulting MP4 exists and is non-empty. It never reports a successful second render based only on a planned command.

## Decision policy

- **ACCEPT**: after semantic QA is verified with zero mismatches.
- **REJECT**: semantic mismatches remain or regression increases.
- **REVIEW**: output cannot be semantically proven.

## Remaining integration

The BIE host must provide the concrete Remotion generator/render commands and connect the after-render OCR provider. The module itself supplies the execution and decision contract.
