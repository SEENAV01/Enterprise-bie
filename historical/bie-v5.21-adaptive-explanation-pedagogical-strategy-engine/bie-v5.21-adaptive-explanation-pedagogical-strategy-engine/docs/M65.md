# M65 — Adaptive Explanation & Pedagogical Strategy Engine

M65 is the learner-aware instructional strategy layer.

## Purpose

The same validated concept does not need to be taught identically to every learner.

M65 converts:
- learner state
- mastery
- concept difficulty
- misconception risk
- learner preferences
into a pedagogical strategy.

## Adaptive dimensions

The strategy can vary:
- explanation depth
- analogy use
- example count
- visual modality
- practice density
- retrieval placement
- pacing policy

## Mastery

Low mastery can trigger foundational explanations and increased practice.

Higher mastery can trigger compact explanations and extension material.

The thresholds in the reference implementation are configurable heuristics, not universal educational laws.

## Misconceptions

High misconception risk can trigger targeted interventions such as contrast plus practice.

The intervention remains linked to the misconception and its evidence references.

## Visual modality

The planner can select a visual modality according to learner preference while allowing upstream visual planning to determine the actual representation.

## Content-driven pacing

Adaptation never means forcing an arbitrary video duration.

Narration and explanation remain content-driven under M58.

## Boundaries

M65 does not alter:
- source truth
- evidence
- domain constraints
- prerequisite facts

It only changes how validated material is taught.

## Relationship to previous modules

M64 defines the curriculum graph.

M65 selects the pedagogical strategy for executing that graph for a particular learner.
