# M89 — Adaptive Curriculum, Path Planning & Next-Best-Learning-Action Engine

M89 converts learner state into an actionable next step.

## Candidate actions

The engine can consider:
- new concept
- prerequisite review
- remediation
- practice
- assessment
- review
- skip
- representation change
- enrichment
- reflection

This makes the next step an explicit decision object.

## Candidate generation vs selection

M89 separates:
1. generating possible actions
2. filtering infeasible actions
3. scoring candidates
4. ranking candidates
5. selecting the next action

This keeps the architecture replaceable and testable.

## Signals

Action ranking can consume signals such as:
- mastery gap
- prerequisite readiness
- misconception risk
- recent performance
- remediation need
- content availability
- pacing constraints

The reference implementation intentionally does not prescribe one universal scoring formula.

A future optimizer can use learned policies, Bayesian decision models, bandits, planning algorithms or domain-specific heuristics.

## Non-linear paths

A path can contain:
- dependencies
- alternatives
- branch conditions

The learner does not have to follow one fixed curriculum.

## Skip as an action

If evidence indicates mastery, `SKIP` can be selected.

This prevents wasting time on already mastered material.

## Representation adaptation

The system can choose a different representation when a learner has a representation gap.

For example:
- symbolic → visual
- visual → verbal
- abstract → concrete

The exact policy remains downstream-configurable.

## Constraints

Required constraints can reject candidate actions.

Examples:
- prerequisite not ready
- required asset unavailable
- assessment not yet appropriate
- pacing restriction

## Decision trace

The planner retains:
- candidate actions
- scores
- rejected actions
- selected action

This supports explainability and debugging.

## Relationship

M88 provides learner state.

M89 chooses the next-best learning action.

The selected action can feed M76–M85 pipelines to generate the actual learning experience.
