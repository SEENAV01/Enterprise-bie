# M62 — Learning-Content Source & Knowledge Ingestion Engine

M62 is the source-ingestion foundation for the BIE system.

## Purpose

The production system needs a reliable representation of the material it is asked to teach.

M62 accepts source material and preserves its structure before downstream reasoning.

## Source types

The schema is source-type agnostic.

Possible source types include:
- PDF
- scanned document
- web source
- textbook
- notes
- structured document

The actual extractor/OCR implementation can be plugged in later.

## Document structure

The ingestion representation preserves:
- document identity
- pages
- reading order
- sections
- hierarchy
- source references

## First-class elements

Equations, tables and figures are represented as explicit elements rather than flattened into plain text.

This is important because educational meaning can depend on:
- mathematical notation
- table relationships
- diagrams
- figure captions

## Semantic chunks

Text is divided into source-linked chunks.

A chunk retains:
- source reference
- section identity
- originating element references
- chunk type

This prevents downstream generation from losing where information came from.

## Citations

Citations are machine-readable records with a source and locator.

The system should preserve exact source locations whenever the extractor can provide them.

## Concept mapping

Chunks can be mapped to concepts with explicit relations and optional confidence.

This becomes the bridge from raw source material to M53 domain reasoning and later pedagogical planning.

## Important boundary

M62 does NOT decide whether a statement is scientifically correct beyond what the source extraction itself establishes.

It also does not silently rewrite the source.

Its job is:

`Source → faithful structured representation`

Downstream reconciliation/validation decides how conflicting or incorrect source claims are handled.

## OCR/extraction uncertainty

If extraction is uncertain, that uncertainty must remain visible in metadata rather than being silently converted into authoritative text.

## Relationship to previous modules

M61 packages provenance for final delivery.

M62 moves to the opposite end of the pipeline: preserving provenance at the source-ingestion stage so that the entire later production chain can remain traceable.
