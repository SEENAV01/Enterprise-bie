# M22 — Multimodal Book Ingestion + Evidence Engine

M22 builds the structured input layer for the BIE.

## Goal

A book is not treated as plain text.

Each page becomes a multimodal record containing:
- text blocks
- figures/images
- tables
- equations
- page metadata

## Page-local context

Before global knowledge extraction, the system preserves relationships between a page's text and its visual assets.

This prevents a figure from becoming an orphan image detached from the paragraph/caption that explains it.

## Evidence

Every extracted item becomes page-level evidence with:
- evidence_id
- page_id
- page number
- modality
- content/description
- asset reference
- provenance

This evidence is what later knowledge-graph and lesson-planning stages should cite.

## Adjacent-page context

Concepts frequently continue across page boundaries. M22 records adjacency so later reasoning can inspect neighboring pages without pretending they are one source block.

## Multimodal index

Evidence is indexed by:
- text
- image
- table
- equation

This supports targeted retrieval later.

## Important boundary

M22 defines the ingestion/evidence contract. It does not pretend that a simple parser has solved OCR, PDF layout reconstruction or complex equation recognition. Production ingestion should plug in specialized PDF/OCR/layout/multimodal extractors while preserving this schema.
