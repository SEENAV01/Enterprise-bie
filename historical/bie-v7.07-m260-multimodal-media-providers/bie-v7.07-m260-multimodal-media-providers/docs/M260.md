# M260 — Multimodal Media Generation Providers

```text
Media Request
 ↓
Provider Registry
 ↓
Primary Provider
 ├── Image
 ├── Diagram
 └── TTS
 ↓
Generated Media
 ↓
Quality Gate
 ↓
Caption Alignment
 ↓
Fallback Provider (on failure)
 ↓
Media Registry / Cache
```

## Provider registry
Providers are registered by media kind, capability and priority.

## Generation
Image and diagram generation requests carry stable asset IDs, prompts and constraints. Provider output is normalized into a common generation result.

## TTS
TTS requests carry text, language and optional voice; accepted output records URI, duration and sample rate.

## Captions
Word-level timestamps can be grouped into readable segments and validated against audio duration.

## Quality gates
Generated media must satisfy required kind/output and metadata constraints before release.

## Fallback
A failed provider can be replaced by the next eligible provider by priority.

## Important boundary
M260 defines provider-agnostic contracts. It does not directly call external image, TTS or caption services. Production adapters plug into these interfaces.
