# M206 — Lesson-to-Script Production Integration

M206 connects the M205 lesson-plan layer to the actual teaching-script layer:

```text
Lesson Plan
    ↓
Script Blocks
    ↓
Objective Coverage
    ↓
Timing
    ↓
Evidence Grounding
    ↓
Verified Teaching Script
```

## Script blocks

The canonical script boundary supports hooks, objectives, explanations, examples, demonstrations, checks for understanding, misconception repair, summaries, retrieval prompts and transitions.

## Objective coverage

Every lesson objective must be represented by one or more script blocks.

## Timing

Blocks carry optional duration. The script can define a target duration and the integration gate checks it within a configurable tolerance.

## Evidence grounding

Script blocks that make instructional claims can retain source evidence IDs. The reference quality gate requires every block to have evidence references.

## Provenance and verification

The script remains linked to its lesson, objectives, evidence and upstream lesson-plan artifact.

## Boundary

M206 does not prescribe a particular LLM, prompting framework, voice, writing style or script-generation provider. It establishes the production contract those generators must satisfy.
