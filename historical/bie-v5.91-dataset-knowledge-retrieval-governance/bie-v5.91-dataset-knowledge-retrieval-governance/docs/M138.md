# M138 — Dataset, Knowledge & Retrieval Governance Layer

M138 governs the information that BIE uses as knowledge for reasoning and generation.

## Dataset identity

Datasets have explicit IDs and versions.

A dataset snapshot captures the version and source references used at a point in time.

## Document and chunk identity

Documents carry stable IDs and content hashes.

Chunks carry:
- chunk ID
- document ID
- chunk hash
- positional boundaries
- optional text reference

This makes retrieval evidence addressable at chunk level.

## Ingestion

Each ingestion run records:
- run ID
- dataset
- source references
- parser version
- start/completion times

This creates ingestion lineage.

## Index governance

Indexes are explicitly versioned and record the embedding model/version used to construct them.

```text
Dataset Version
      ↓
Index Version
      ↓
Embedding Version
```

## Retrieval evidence

A retrieval query records:
- query ID
- query text
- index reference
- top-k
- filters

Each hit records the chunk reference, score and rank.

The resulting retrieval evidence can therefore be attached to a knowledge snapshot.

## Freshness

Resources can have a maximum age. The reference implementation can flag a resource as stale when its observation age exceeds that limit.

## Access constraints

Datasets can declare allowed actions for a principal scope.

This is complementary to M132 authorization; M138 defines knowledge-specific constraints while M132 provides the broader identity/authorization boundary.

## Knowledge snapshots

Before generation, the system can freeze:

```text
Dataset Version
+
Index Version
+
Retrieved Chunks
+
Retrieval Scores
+
Timestamp
```

into a knowledge snapshot.

That snapshot can be referenced by downstream provenance.

## Relationship

M137 records computational provenance.

M138 records the governed knowledge state consumed by the computation.

Together:

```text
Knowledge Snapshot
       ↓
Model Execution
       ↓
Artifact Provenance
       ↓
Output
```

## Important boundary

Retrieval evidence is not itself proof that a source is correct. Source authority, licensing, access rights and content quality require separate governance and evaluation.
