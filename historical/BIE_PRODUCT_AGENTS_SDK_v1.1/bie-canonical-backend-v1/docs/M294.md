# M294 — Source-vs-Render Semantic Verification + Repair

M294 creates the first grounded comparison between expected visual content and what OCR detected in rendered frames.

```text
Grounded Scene DSL
       ↓
Expected Equation / Diagram Text
       ↓
Rendered Frame
       ↓
OCR
       ↓
Expected ↔ Detected Comparison
       ↓
Mismatch
       ↓
Grounded Repair Patch
       ↓
Re-render (next execution layer)
```

## Implemented

- expected visual extraction from Scene DSL
- OCR-vs-source text comparison
- explicit `verified / mismatch / not_proven` status
- grounded repair patches
- deterministic source DSL hash
- semantic mismatch QA gate
- tests + contract

## Critical safety rule

The repair system can only restore text that already exists in the grounded Scene DSL. It cannot invent a new equation, value, label or explanation.

M294 generates the repair patch. Full automatic application + re-render is the next execution milestone.
