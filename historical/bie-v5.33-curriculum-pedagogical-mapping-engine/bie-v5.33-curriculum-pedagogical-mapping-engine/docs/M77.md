# M77 — Curriculum & Pedagogical Mapping Engine

M77 converts structured knowledge into an explicit learning plan.

It represents learning objectives, prerequisite dependencies, teaching strategies, misconceptions, examples, practice opportunities and mastery checkpoints.

The objective dependency graph is topologically ordered. Cycles block compilation.

Pedagogical structure is deliberately separated from rendering. M77 decides what should be learned and the teaching sequence; downstream visual, audio, temporal and rendering modules decide how that sequence is produced.

The architecture is domain-agnostic and can support science, mathematics, humanities, programming and professional education.

M76 supplies the knowledge graph. M77 transforms it into a pedagogical plan. M67/M68/M69 consume that plan for multimodal production.
