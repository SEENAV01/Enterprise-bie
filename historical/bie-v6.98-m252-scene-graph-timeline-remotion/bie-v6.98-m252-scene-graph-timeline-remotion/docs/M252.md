# M252 — Scene Graph Composition, Timeline Dependency Resolution, Camera/Layer Planning & Render-Ready Remotion Scene Contracts

```text
Grounded Scene Specification
          ↓
       Scene Graph
          ↓
  Timeline Dependencies
          ↓
    Layer + Z Planning
          ↓
      Camera Plan
          ↓
 Render-Ready Remotion Contract
          ↓
       Validation Gate
```

## Scene graph
Visual, equation, annotation and narration components become explicit nodes and dependency edges.

## Timeline
Events have frame ranges and can be dependency-ordered before rendering.

## Layer planning
Elements receive deterministic z-index values so the renderer has a stable visual stacking order.

## Camera planning
Shots specify frame ranges, focus, scale, pan and transition.

## Remotion contract
The output contains duration, FPS, layers, camera, timeline and audio fields and is explicitly marked for the Remotion renderer.

## Boundary
M252 creates the renderer contract; it does not execute Remotion or encode an MP4. The next integration stage connects this contract to actual composition generation and render orchestration.
