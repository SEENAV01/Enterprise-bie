# M21 — Asset Intelligence Layer

M21 gives the video system an explicit asset intelligence layer.

## Core decision

For every visual extracted from a book, the system decides:

1. REUSE_SOURCE — source visual is good enough.
2. RECONSTRUCT — source visual is useful but needs editable/vector structure.
3. GENERATE_FALLBACK — no adequate source visual exists.

The decision is evidence-driven and recorded in the asset record.

## Asset classes

figure, diagram, photo, illustration, chart, table, equation, formula, map, timeline, screenshot, decorative, unknown.

## Quality

Quality is not only resolution. The initial score considers:
- dimensions
- OCR confidence
- caption availability

Production can extend this with image sharpness, crop integrity, visual complexity, diagram parse confidence and semantic match.

## Provenance

Every source asset retains source page and book provenance.
Generated fallback visuals are explicitly marked EXTERNAL_GENERATED and require review when fidelity matters.

## Reconstruction

Important diagrams should become editable vector scenes containing:
- labels
- shapes
- arrows
- relationships
- regions
- quantities

This allows animation without repeatedly regenerating the entire image.

## Cache

Asset transformations receive deterministic content hashes so the same book asset does not need to be processed repeatedly.

## Critical rule

The system must never silently replace a source diagram with an invented visual when source fidelity matters. It must know whether it is reusing, reconstructing or generating.
