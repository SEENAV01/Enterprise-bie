# M298 — Production Adapter Wiring

M298 turns M297's orchestration contract into an executable production wiring layer.

```text
Production Render Adapter
        ↓
Frame Sampling Adapter
        ↓
OCR Adapter
        ↓
Semantic QA Adapter
        ↓
   ACCEPT ─────────→ DONE
        │
      REJECT
        ↓
Repair Adapter
        ↓
Regeneration Adapter
        ↓
      RENDER
        ↺
```

## Implemented

- required production adapter validation
- end-to-end adapter invocation
- bounded repair/re-render cycles
- explicit failure propagation
- testable dependency injection
- audit history

## Important

The wiring layer does not invent concrete commands or hide unavailable dependencies. The host application must supply the actual adapters.
