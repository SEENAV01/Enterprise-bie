
## Ingestion
Documents receive stable IDs and source/version metadata.

## Chunking
Documents are split into bounded overlapping chunks with stable chunk IDs.

## Indexing and retrieval
The baseline provides lexical retrieval plus a hybrid fusion contract that can combine lexical and semantic scores.

## Reranking
A reranking hook is provided for production cross-encoder or model-based ranking.

## Citations
Retrieved chunks map back to document IDs, source versions and chunk locators.

## Freshness
Current/stale/future source versions are classified and stale sources can be rejected unless explicitly allowed.

## Boundary
M276 defines retrieval and grounding contracts. It does not implement a production vector database, embedding model, OCR pipeline or web crawler.
