# M288 — Real Remotion Generator

M288 crosses the boundary from abstract Scene DSL to actual Remotion source code.

```text
Scene DSL 1.0
      ↓
Remotion Project Generator
      ↓
Root.tsx + BIELesson.tsx + index.tsx
      ↓
Remotion CLI
      ↓
MP4
```

## Implemented

- actual TSX generation
- Remotion Composition
- scene-to-Sequence conversion
- deterministic seconds → frames conversion
- renderer-ready project structure
- generation validation
- QA integration
- tests + contract

## Important boundary

M288 generates a **real Remotion project**. It does not claim the MP4 has already been rendered.

The next renderer step executes the generated project.
