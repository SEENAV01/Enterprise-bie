# M224 — Asset Quality Scoring, Perceptual Similarity, Visual Regression & Automatic Repair/Re-generation

```text
Generated Asset
      ↓
Quality Scoring
 ┌────┼────┬────┐
Tech Semantic Visual Consistency
      ↓
Perceptual Similarity
      ↓
Visual Regression / Diff
      ↓
Quality Gate
  ├── ACCEPT
  └── REPAIR PLAN
          ↓
     RE-GENERATE
          ↓
      Re-check
          ↓
      ESCALATE
```

## Quality scoring
Technical, semantic, visual and consistency scores are combined using configurable weights.

## Perceptual similarity
Reference and candidate feature sets are compared to estimate semantic/perceptual overlap.

## Visual regression
Baseline and current quality metrics are compared against a tolerance.

## Visual diff
Added, removed and unchanged features provide a compact regression explanation.

## Repair planning
Failures map to targeted actions such as visual re-rendering, semantic regeneration, layout matching or technical fixes.

## Bounded regeneration
Regeneration attempts are limited. When the limit is exhausted, the pipeline escalates instead of looping indefinitely.

## Boundary
M224 provides deterministic reference contracts. Production implementations can use computer-vision embeddings, pixel/perceptual metrics and renderer-specific regression systems.
