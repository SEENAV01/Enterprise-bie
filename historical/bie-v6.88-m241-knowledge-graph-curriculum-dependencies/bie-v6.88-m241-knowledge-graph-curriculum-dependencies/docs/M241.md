# M241 — Knowledge Graph Construction, Concept Relations, Prerequisite Graphs & Curriculum Dependency Validation

```text
Concepts + Lessons
       ↓
 Typed Knowledge Graph
       ↓
 Concept Relations
       ↓
 Prerequisite Graph
       ↓
 Cycle Detection
       ↓
 Curriculum Dependency Order
       ↓
 Knowledge Graph Gate
```

## Knowledge graph
Concepts and lessons are represented as typed nodes connected by semantic edges.

## Relations
The baseline relation vocabulary includes PREREQUISITE, RELATED, PART_OF, EXAMPLE_OF and DEPENDS_ON.

## Prerequisites
Prerequisite edges are converted into a target-to-required-skills map.

## Cycle detection
Prerequisite cycles are rejected because they make curriculum ordering impossible.

## Curriculum dependency validation
A topological dependency order is generated so prerequisites precede dependent concepts.

## Boundary
M241 defines graph and dependency contracts. It does not infer relations from raw text; a future extraction layer can populate the graph from grounded educational content.
