# M188 — Identity, Access Control & Authorization Policy Layer

M188 defines vendor-neutral identity and authorization contracts.

## Principals

Supported principal kinds:

```text
USER
SERVICE
GROUP
```

A principal has an explicit active/inactive lifecycle state.

## Roles and permissions

Roles group permissions and may reference parent roles.

A permission consists of an action, resource and optional conditions.

## Resource scopes

Scopes define the resources to which delegated or policy-controlled access applies.

## Authorization

The reference decision contract returns:

```text
ALLOW
DENY
```

with an explicit reason.

The evaluator is intentionally minimal and can be replaced by M187 policy evaluation hooks.

## Delegation

Delegation records:
- delegator
- delegatee
- scope
- optional expiry

Delegation is explicit rather than implied by possession of credentials.

## Service identities

Services receive their own identity boundary and may reference a credential managed by M165.

## Credential boundaries

Credential use can be constrained by issuer and audience.

## Audit

Authorization decisions produce audit events suitable for M150 and downstream security/audit systems.

## Relationship

```text
M165 → Keys / Credentials
M174 → Configuration
M180 → External Integration
M182 → Workflow
M184 → Transaction / Effect Safety
M187 → Policy / Decision Engine
M188 → Identity / Authorization
M150 → Audit / Observability
```

## Important boundary

M188 does not implement a specific IAM vendor, OAuth/OIDC server, LDAP directory, or cryptographic credential issuer. It provides the identity and authorization contracts those systems can implement.
