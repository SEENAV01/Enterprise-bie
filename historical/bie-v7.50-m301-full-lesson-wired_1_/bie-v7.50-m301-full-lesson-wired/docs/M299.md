# M299 — Concrete Runtime Adapters

M299 replaces abstract production dependencies with concrete command adapters.

## Runtime adapters

- **Remotion:** executes a supplied project command.
- **FFmpeg:** samples real frames from the MP4.
- **Tesseract:** runs real TSV OCR.
- **MP4 verifier:** validates artifact existence and optionally uses ffprobe.

```text
Remotion
   ↓
real MP4
   ↓
FFmpeg
   ↓
real frames
   ↓
Tesseract
   ↓
real OCR
   ↓
QA
```

No adapter invents successful output when its dependency is unavailable.
