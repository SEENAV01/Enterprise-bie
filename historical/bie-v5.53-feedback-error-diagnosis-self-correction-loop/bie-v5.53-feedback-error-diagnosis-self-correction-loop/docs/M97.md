# M97 — Feedback, Error Diagnosis & Self-Correction Loop

M97 closes the production loop.

## Why

M96 can identify that an artifact failed.

M97 decides what to do about that failure.

The system should not respond to every failure with blind regeneration.

## Diagnosis

A validation failure becomes a structured diagnosis containing:
- error type
- severity
- evidence
- likely causes
- confidence

Supported error categories span:
- source
- content
- pedagogy
- representation
- timing
- audio
- visual
- interaction
- accessibility
- renderer
- contract
- system

## Root-cause routing

The diagnosis can route correction to an upstream layer.

Examples:
- source failure → M90 retrieval
- content failure → M91 transformation
- representation failure → M92 planning
- contract failure → M93
- build failure → M94
- renderer failure → M95
- timing failure → temporal planning
- pedagogical failure → adaptive planning

The mapping is explicit and replaceable.

## Corrective actions

Possible actions include:
- retrieve
- transform
- change representation
- update contract
- change backend
- regenerate
- review
- retry
- rollback
- no action

The action is selected from the diagnosed problem rather than being universally `REGENERATE`.

## Closed loop

The basic cycle becomes:

`Produce → Validate → Diagnose → Correct → Rebuild → Revalidate`

The loop can continue until the artifact passes or the system escalates.

## Guardrails

Self-correction needs limits.

M97 supports:
- maximum iteration count
- repeated-failure detection
- low-confidence diagnosis escalation
- critical-error escalation

This prevents uncontrolled regeneration loops.

## Human review

Human review is a first-class outcome.

The system can stop when:
- diagnosis confidence is too low
- failures repeat
- severity is critical
- automated correction is unsafe or ambiguous

## Traceability

Each correction plan identifies:
- diagnosis
- target layer
- action
- candidate causes
- whether revalidation is required

This makes automated correction auditable.

## Relationship

M96 produces validation evidence.

M97 interprets that evidence and routes correction.

The correction may return to almost any upstream module.
