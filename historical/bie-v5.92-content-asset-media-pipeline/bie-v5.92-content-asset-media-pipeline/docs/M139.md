# M139 — Content / Asset Transformation & Media Pipeline Layer

M139 provides a governed production pipeline for content and media assets.

## Unified asset identity

Every asset has:
- asset ID
- kind
- content hash
- MIME type
- size
- metadata

The same identity model can represent documents, images, audio, video and derived outputs.

## Media metadata

The reference model can capture:
- dimensions
- duration
- codec
- frame rate
- sample rate
- channels

Metadata validation can be applied according to asset kind.

## Normalization

Raw assets can pass through normalization steps before entering downstream composition.

```text
Raw Asset
   ↓
Normalize
   ↓
Canonical Asset
```

## Transformation

Transformations are explicit pipeline steps with:
- operation
- inputs
- output
- parameters

This creates transformation lineage.

## Transcoding and variants

A source can produce multiple controlled variants.

```text
Master
 ├── Web Video
 ├── Mobile Video
 └── Preview
```

Codec, container, format and quality can be recorded for each variant.

## Composition

Composition inputs explicitly identify the asset and its role in a timeline.

This is important for BIE's video-generation pipeline.

## Rendering

Render jobs reference a composition and target output format.

Completed renders return output references, hashes and basic media measurements.

## Compatibility

Input/output compatibility can be checked before a transformation or render stage.

## Media quality

Media-specific checks can validate objective properties before an asset proceeds.

## Relationship

M137 supplies provenance.

M138 supplies governed knowledge inputs.

M139 turns assets and generated content into a structured transformation pipeline.

M135/M136 can evaluate and approve the resulting assets.

## Important boundary

The reference implementation models pipeline metadata and governance; it does not itself perform codec conversion, rendering or media processing. Production workers such as FFmpeg, image processors or render engines must execute the actual transformations under the governed pipeline.
