# M282 — Book Structure Compiler

M282 converts the page/block-oriented Document IR into a deterministic book hierarchy.

```text
Document IR 2.1
      ↓
Heading Detection
      ↓
Hierarchy Compiler
      ↓
Chapter / Unit / Section Tree
      ↓
Flat Source Index
      ↓
Planning Units
      ↓
Knowledge + Lesson Planning
```

## Implemented

- deterministic nested section tree
- numbered heading hierarchy
- chapter/unit/part/lesson/module recognition
- TOC-like heading filtering
- stable source block references
- flat section index
- planning units
- hierarchy validation
- canonical pipeline integration
- tests and contract

## Why this is the next product bottleneck

A full book cannot reliably become a course/video from isolated pages. The downstream planner needs a durable representation of chapters, sections and source blocks so it can select coherent teaching units and maintain traceability.

## Important boundary

M282 does not claim perfect heading semantics for every publisher or book layout. It provides a deterministic baseline and exposes the structure as an explicit artifact. Publisher-specific or ML-based hierarchy correction can be added behind this contract later.
