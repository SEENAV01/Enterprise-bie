# M284 — Semantic Retrieval & Concept Linking

M284 turns M283's grounded knowledge into something the downstream planner can actually retrieve.

```text
Book Structure + Grounded Knowledge
              ↓
       Section Documents
              ↓
      Lexical Retrieval Index
              ↓
          Query Search
              +
    Cross-section Concept Links
              ↓
       Retrieval IR 1.0
              ↓
          Lesson Planner
```

## Implemented

- dependency-free TF-IDF lexical retrieval
- section-level searchable documents
- deterministic query ranking
- cross-section links for the same grounded entity
- evidence references on concept links
- retrieval validation
- replaceable index contract
- canonical pipeline integration
- tests

## Important boundary

This is intentionally not marketed as an embedding/vector database yet. The interface is designed so a production ANN/embedding backend can replace the lexical index without changing downstream contracts.

M284 also does not infer new facts when linking concepts. A link means the same grounded entity appears in multiple source sections.
