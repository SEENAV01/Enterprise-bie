# M204 — Knowledge Graph & Learning-Graph Production Integration

M204 connects the verified multimodal knowledge produced by M202/M203 into the learning-reasoning layer.

```text
Grounded Knowledge
       ↓
Knowledge Graph
       ↓
Prerequisites / Dependencies
       ↓
Learning Graph
       ↓
Pedagogical Planning
```

## Knowledge Graph

Concept nodes and evidence-backed relationships form the canonical knowledge graph.

## Learning Graph

Learning nodes and dependency/prerequisite edges form the canonical learning graph.

## Ontology

Canonical terms carry aliases, hierarchy metadata and evidence references.

## Provenance

Graphs remain traceable to source/evidence and upstream artifacts.

## Verification

The graph integration is accepted only through an explicit PASS/FAIL/REVIEW gate.

## Boundary

M204 does not implement a specific graph database, graph neural network or curriculum optimizer. It defines the production integration contract for those later adapters.
