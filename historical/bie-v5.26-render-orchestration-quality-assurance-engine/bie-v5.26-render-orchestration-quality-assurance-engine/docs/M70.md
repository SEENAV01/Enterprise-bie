# M70 — Render Orchestration & Quality Assurance Engine

M70 is the production reliability layer between compiled Remotion scenes and final video output.

## Preflight

Before rendering, the system checks:
- required assets exist
- audio/video duration consistency
- deterministic frame count
- composition metadata

A failed preflight blocks release.

## Render jobs

A render job explicitly records:
- project
- composition
- output path
- codec
- quality
- status

The reference implementation separates job description from actual renderer execution.

## Caching

A deterministic SHA-256 fingerprint is generated from the compiled specification.

This enables:
- cache hits for unchanged scenes
- reproducible builds
- avoiding unnecessary rerenders

## Retry handling

Transient failures can be retried according to a configurable policy.

Permanent validation failures should not be blindly retried.

## Preview

Preview jobs allow partial/low-scale renders before committing to a full render.

## QA

QA combines:
- asset validation
- timing checks
- frame checks
- render result status

Only a passing QA report becomes `RELEASE_READY`.

## Final MP4

M70 defines the orchestration and release gate.

The actual MP4 encoder/Remotion renderer is an execution dependency downstream of this specification.

## Relationship to M69

M69 produces renderable scene/composition specifications.

M70 assembles, validates, schedules, caches and quality-gates their execution.
