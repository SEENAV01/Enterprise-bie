# M267 — Distributed Job Queue & Dependency Scheduler

```text
Course DAG
   ↓
Dependency Validation
   ↓
Ready Jobs
   ↓
Priority Queue
   ↓
Concurrency / Worker Capacity
   ↓
Dispatch
   ↓
Success ─────────→ Downstream Jobs
   │
 Failure
   ↓
Retry + Backoff
   ↓
Attempt Limit
   ↓
Failed / Escalate
```

## DAG
Dependencies are validated for unknown nodes and cycles. Only jobs whose dependencies are complete become ready.

## Priority queue
Ready jobs are ordered by descending priority and stable job ID.

## Retries
Failures increment the attempt counter and use exponential backoff until the attempt limit is reached.

## Idempotency
Execution keys prevent duplicate acceptance of the same job attempt.

## Concurrency
Schedulers can limit active parallel work.

## Critical path
Dependency durations provide a path metric for identifying schedule pressure.

## Boundary
M267 defines scheduling contracts; it does not replace a production queue broker or distributed lock service.
