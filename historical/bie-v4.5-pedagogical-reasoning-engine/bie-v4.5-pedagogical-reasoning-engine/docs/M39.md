# M39 — Pedagogical Reasoning Engine

M39 converts the universal content decomposition into a preliminary teaching plan.

## Core problem

Extraction answers:

> What information exists?

Pedagogy answers:

> What should a learner understand, in what order, at what depth, and through what teaching mode?

M39 is the bridge.

## Importance scoring

Each extracted item can be scored using signals such as:
- dependency count
- downstream dependency count
- exam relevance
- graph centrality
- practical relevance
- misconception risk

The result is classified as:
- CORE
- IMPORTANT
- SUPPORTING
- ENRICHMENT

The scoring layer is intentionally configurable. It is not a universal truth about importance.

## Prerequisite order

The dependency graph is topologically ordered so prerequisite knowledge appears before dependent knowledge.

Cycles block automatic ordering instead of being ignored.

## Teaching mode

The decomposed dimension influences presentation:

DEFINITION / WHAT → explain
WHY → causal explanation
HOW / PROCESS → demonstrate
DERIVATION / FORMULA → step-by-step derivation
APPLICATION → applied example/use case
COMPARISON → compare
EXCEPTION / LIMITATION → boundary/contrast
COUNTEREXAMPLE → counterexample

This is only the first pedagogical decision. Later systems can use learner level, objectives, time budget and assessment performance to adapt it.

## Teaching units

Each knowledge item becomes a potential teaching unit containing:
- source grounding
- importance
- objectives
- teaching mode
- prerequisites
- assessment hooks

## Important design principle

M39 does NOT impose a fixed duration per concept.

A simple definition may take seconds. A difficult derivation may require several minutes and multiple scenes.

Timing will be determined downstream from:
- explanation complexity
- narration
- learner comprehension needs
- visual requirements
- derivation steps
- examples
- audio synchronization

## What comes next

M40 should build the Adaptive Lesson Architect: turn teaching units into complete lesson structures with introduction, prerequisite recall, explanation, intuition, derivation, examples, applications, misconception checks, recap and assessment—while deciding what should be narrated, visualized, animated, written as equations, or left as supporting text.
