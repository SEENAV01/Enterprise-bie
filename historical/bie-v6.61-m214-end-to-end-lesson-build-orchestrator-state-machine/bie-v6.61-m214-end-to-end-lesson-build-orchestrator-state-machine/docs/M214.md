# M214 — End-to-End Lesson Build Orchestrator & State Machine

M214 connects the previous BIE production blocks into one controlled lesson-build lifecycle:

```text
Input
 ↓
INGESTED
 ↓
UNDERSTOOD
 ↓
PLANNED
 ↓
SCRIPTED
 ↓
STORYBOARDED
 ↓
ASSETS_READY
 ↓
AUDIO_READY
 ↓
COMPOSED
 ↓
RENDERED
 ↓
QA_EVALUATED
 ├── PASS → VERIFIED
 └── FAIL → REMEDIATION → affected stage → ... → QA
```

## State machine

Every lesson job has one authoritative lifecycle state. Invalid transitions are rejected.

## Stage contracts

Each major stage declares the artifact type required to enter/complete it.

## Artifact registry

Artifacts are registered with stable IDs, types, URIs, stage ownership and optional checksums.

## Event history

Every state transition is recorded with reason and optional artifact/evidence references.

## Checkpoints

The pipeline can persist a resumable checkpoint so a long lesson build does not need to restart from ingestion after interruption.

## Failure policy

Remediation is bounded by a configurable cycle limit, with critical failures able to force terminal failure.

## Provenance

Source, state events, artifacts and checkpoints remain linked to the lesson job.

## Final verification

A lesson reaches VERIFIED only when the final verification contract passes.

## Boundary

M214 is the orchestration/control layer. It does not replace the specialist modules M201–M213; it coordinates their contracts and artifacts.
