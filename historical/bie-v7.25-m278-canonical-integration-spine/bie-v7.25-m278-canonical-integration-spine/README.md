# BIE v7.25 — M278 Canonical Integration Spine

This milestone changes the build strategy from isolated module ZIPs to one canonical executable product pipeline.

M278 does not add another duplicate intelligence subsystem. It defines the integration boundary that connects the existing BIE layers into one traceable run:

SOURCE → UNDERSTAND → KNOWLEDGE → PLAN → SCRIPT → SCENE → REMOTION → RENDER → QA → PUBLISH

The included implementation is a deterministic orchestration spine with replaceable adapters. Provider-specific PDF parsing, LLM calls, TTS, asset generation and rendering can be attached behind these contracts.
