# M287 — Scene DSL Compiler

M287 converts the grounded Script IR into an explicit renderer-independent Scene DSL.

```text
Grounded Script
      ↓
Scene Compiler
      ↓
┌───────────────┬──────────────┬──────────────┐
│ Timing        │ Narration    │ Visual Spec  │
└───────────────┴──────────────┴──────────────┘
      ↓
Scene DSL 1.0
      ↓
Remotion Generator
```

## Implemented

- deterministic scene generation
- narration/audio specification
- duration estimation
- title and source-text visual specifications
- source-block grounding carried into scenes
- renderer-independent scene contract
- validation + QA gate
- tests

## Important boundary

M287 is **not yet the final visual intelligence layer**.

The generated visuals are explicit specifications/placeholders. It does not claim that an equation has been typeset, a diagram generated, or an animation rendered.

That separation is deliberate: the next renderer stage can consume a stable Scene DSL while richer visual primitives are added without changing the upstream book/knowledge/planning contracts.
