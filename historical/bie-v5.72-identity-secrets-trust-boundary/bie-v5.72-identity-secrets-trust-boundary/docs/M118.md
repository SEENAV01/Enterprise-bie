# M118 — Identity, Secrets & Trust Boundary Layer

M118 establishes explicit trust boundaries between actors, generated content, workers, production systems and protected resources.

## Core principle

```text
Model output
    ≠
Trusted code
    ≠
Production authority
```

Generated output is untrusted by default.

## Identity

An identity records:
- stable identity ID
- identity kind
- roles
- attributes
- issuer

The model should not be treated as an implicit privileged identity.

## Scoped credentials

Credentials have explicit scopes.

An operation requires both:
1. an allowed trust-boundary crossing
2. a credential containing the required operation scope

This creates two independent controls.

## Secrets

The architecture uses secret references rather than embedding secret values into generated artifacts or prompts.

A reference can identify:
- secret identity
- secret version

Actual secret storage belongs to a protected secret-management implementation.

## Trust zones

Reference zones:

```text
UNTRUSTED
   ↓
SANDBOX
   ↓
WORKER
   ↓
PRODUCTION
   ↓
PROTECTED
```

Cross-zone movement is explicitly controlled.

The reference policy is illustrative and should be tightened according to deployment requirements.

## Model-output isolation

Generated content can be marked as executing in a sandbox.

The isolation record makes privilege escalation an explicit boundary decision rather than an accidental property of generated code.

## Rotation

Credentials and secrets can have rotation records containing:
- rotation ID
- old version
- new version
- timestamp
- status

This connects credential lifecycle changes to M116 audit events.

## Important boundary

M118 does not implement a secret vault, identity provider or operating-system sandbox.

It defines the architectural contracts that those implementations must satisfy.

## Relationship

M117 determines whether an operation is authorized under governance policy.

M118 determines whether the actor, credential and trust boundary permit the operation to reach the target zone.

M116 can record all resulting security decisions.

M101–M104 execute only after these boundaries are satisfied.
