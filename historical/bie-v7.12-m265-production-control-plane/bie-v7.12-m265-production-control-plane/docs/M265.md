# M265 — Production Control Plane

```text
Course / Lesson / Scene / Run
          ↓
   Lifecycle State Machine
          ↓
 Run Management + Operator Controls
          ├── Pause
          ├── Resume
          └── Cancel
          ↓
      Completion
          ↓
   Release Approval
          ↓
    Deployment Gate
          ↓
       RELEASED
```

## Lifecycle
Explicit states prevent arbitrary transitions and make production runs controllable.

## Operator controls
Pause, resume and cancel commands are represented separately from execution state changes.

## Approval
Completed runs can enter AWAITING_APPROVAL and require an explicit release decision.

## Deployment gate
Release requires QA pass, approval, verified artifact and valid observability.

## Audit
State-changing actions record actor, before/after state and reason where applicable.

## Boundary
M265 is the control-plane contract. It does not itself deploy infrastructure or enforce OS-level process termination; those adapters consume the commands.
