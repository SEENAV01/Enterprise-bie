# M137 — Artifact Provenance, Lineage & Reproducibility Layer

M137 makes every important BIE artifact explainable and reconstructable from recorded computational context.

## Provenance manifest

An artifact manifest records:
- artifact ID
- artifact hash
- inputs
- model
- prompt
- configuration
- code version
- dependencies
- environment

The reference model marks manifests immutable after creation.

## Hashes

Canonicalized records and artifacts can be hashed with SHA-256 in the reference implementation.

Hashes provide integrity evidence and stable references to content.

## Lineage

Lineage represents parent/child relationships:

```text
Source
  ↓
Lesson
  ↓
Scene
  ↓
Render
  ↓
Published Artifact
```

A lineage graph can be queried for ancestors.

## Dependency snapshots

Reproduction requires more than source inputs.

The system therefore records dependency groups such as:
- packages
- assets
- runtimes

## Reproduction fingerprint

A fingerprint can be computed from:

```text
Model
Prompt
Config
Code
Dependencies
Environment
```

A future execution can compare its fingerprint against the recorded one.

## Replay plan

The manifest can be transformed into a replay plan containing the computational inputs and versions needed to attempt reconstruction.

The reference implementation checks that core fields are present before declaring the plan replay-ready.

## Artifact verification

The artifact hash can be recomputed and compared with the manifest.

```text
Recorded Hash
     vs
Actual Hash
     ↓
MATCH / MISMATCH
```

## Relationship

M131 governs artifact lifecycle.

M137 records why/how an artifact exists and what it depends on.

M135 evaluates output quality.

M136 records human decisions.

M134 provides operational telemetry.

Together these layers make an artifact both **governed and explainable**.

## Important boundary

Reproducibility metadata does not guarantee bit-for-bit deterministic replay. External APIs, nondeterministic model behavior, hardware differences and unavailable dependencies can prevent exact reconstruction. Production systems should record deterministic seeds where applicable, external-response snapshots where permitted, container/image digests and environment locks.
