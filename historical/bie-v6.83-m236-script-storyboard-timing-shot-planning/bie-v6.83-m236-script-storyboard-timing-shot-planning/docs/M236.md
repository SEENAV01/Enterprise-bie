# M236 — Script Generation, Storyboard Construction, Scene Timing, Narration Synchronization & Shot Planning

```text
Objectives + Concepts
        ↓
    Script Segments
        ↓
     Storyboard
        ↓
   Scene Timing
        ↓
Narration Synchronization
        ↓
     Shot Plan
        ↓
 Video Planning Gate
```

## Script generation
Learning objectives and linked concepts are converted into deterministic script segments.

## Storyboard
Each script segment receives a visual shot contract and transition.

## Timing
Segment duration is estimated from narration length and configurable words-per-minute.

## Narration synchronization
Narration text is assigned exact start/end timestamps from the generated timeline.

## Shot planning
Storyboard shots inherit their synchronized timeline, producing a render-oriented shot plan.

## Validation
The pipeline rejects non-monotonic narration timelines and invalid shot durations.

## Boundary
M236 is a planning layer; it does not synthesize the final audio, images or video. Downstream renderers consume the shot plan.
