# M151 — Metrics, SLO, Alerting & Reliability Policy Layer

M151 turns M150 telemetry into explicit reliability objectives and operational signals.

## SLI

A Service Level Indicator measures observed service behavior.

The reference model supports event-based ratio SLIs such as:

```text
good events / total events
```

## SLO

An SLO defines a target for an SLI over a declared window.

Example:

```text
Availability SLO = 99.9%
Window = 30 days
```

The reference helper evaluates whether an observed SLI meets the target.

## Error budget

For an availability-style SLO:

```text
allowed error ratio = 1 - SLO target
```

The error budget represents the amount of unreliability that can be tolerated before reliability policy requires attention.

## Burn rate

Burn rate compares observed error ratio with the allowed error ratio.

```text
burn rate =
observed error ratio / allowed error ratio
```

A burn rate above a policy threshold can trigger an alert.

## Alert rules

Rules define:
- ID
- name
- condition
- severity
- required duration

The reference evaluator maps observed boolean signals to rule activation.

## Incidents

Incident state provides:
- ID
- title
- severity
- service
- start time
- source
- status

Incidents can transition to RESOLVED.

## Suppression

Alert suppression represents controlled periods where a rule should not page.

Suppression should be explicit, bounded where possible, and auditable in production.

## Reliability policy

A service can declare SLO targets and default alert severity.

This becomes a policy input for future automated operational decisions.

## Relationship

```text
M150 Telemetry
      ↓
     SLI
      ↓
     SLO
      ↓
Error Budget
      ↓
 Burn Rate
      ↓
 Alert
      ↓
 Incident
```

M147 health signals can provide additional operational inputs.

M134 can consume these signals for system-level monitoring.

## Important boundary

The reference implementation does not implement a production metrics backend, alert delivery system, paging service, incident-management platform, statistical anomaly detector or multi-window burn-rate engine.
