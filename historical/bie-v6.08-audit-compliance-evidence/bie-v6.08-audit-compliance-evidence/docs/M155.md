# M155 — Audit, Compliance Evidence & Policy Attestation Layer

M155 converts security and governance decisions into reviewable evidence.

## Audit events

An audit event records:
- event identity
- event type
- actor
- resource
- action
- outcome
- timestamp
- trace ID
- policy version
- evidence references

## Integrity

Audit records can carry integrity metadata including:
- previous hash
- event hash
- algorithm

This provides a contract for append-oriented or chained audit storage.

The reference implementation does not calculate cryptographic hashes.

## Evidence

Evidence records identify:
- evidence ID
- type
- source
- creation time
- content reference
- integrity metadata
- collection status

## Evidence bundles

A bundle groups evidence for a particular control and review period.

```text
Control
  ↓
Evidence
  ↓
Evidence Bundle
```

## Control mapping

A control maps a requirement to one or more evidence references and has a review status.

## Attestation

An attestation records:
- reviewer
- control
- status
- review time
- evidence references
- notes

Supported conceptual outcomes include PASS, FAIL and REVIEW.

## Compliance snapshots

A snapshot captures control statuses for a period, enabling point-in-time reporting.

## Provenance

Evidence provenance identifies where evidence originated, who collected it and when.

This makes evidence lineage explicit.

## Evidence retention

Evidence can have its own retention policy, independent of the data retention policy in M154.

## Relationship

```text
M152 Security
      ↓
M154 Governance
      ↓
M155 Audit Event
      ↓
Evidence
      ↓
Control Mapping
      ↓
Attestation
      ↓
Compliance Snapshot
```

M150 trace IDs can connect audit events to distributed execution.

M153 protects the cryptographic material used by production integrity mechanisms.

## Important boundary

The reference implementation does not provide an immutable ledger, certified compliance opinion, cryptographic hash engine, external auditor workflow, legal interpretation or a production evidence repository.
