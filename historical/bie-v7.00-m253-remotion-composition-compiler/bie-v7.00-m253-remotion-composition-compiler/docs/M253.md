## Composition compiler
Converts scene metadata into a deterministic composition definition containing dimensions, FPS, duration and component identity.

## React code generation
Creates a minimal Remotion-compatible React component structure from the compiled layers.

## Asset binding
Scene layer asset IDs are resolved against an asset registry before rendering.

## Render job
The output contract specifies composition, output path, codec, FPS, duration and readiness state.

## Metadata
Renderer-facing metadata is retained for downstream orchestration and QA.

## Important boundary
M253 establishes the **code-generation/render-job boundary**. It does not execute the Remotion renderer or create the final MP4 itself. Actual rendering belongs to the render executor/integration stage.

## Architecture checkpoint
At this point the pipeline reaches:

`Content → Pedagogy → Assessment → Scene → Remotion Contract → Code/Render Job`

The next work should focus on **integration, execution, QA and production reliability**, rather than blindly increasing the M-number.
