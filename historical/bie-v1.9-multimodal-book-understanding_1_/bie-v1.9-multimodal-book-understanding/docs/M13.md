# M13 — Multimodal Book Understanding

M13 connects the layout-aware document IR to a multimodal reasoning boundary.

## Input to the model

The model receives:
- ordered text blocks
- page numbers
- heading structure
- evidence IDs
- bounding boxes
- figure references
- table references
- equation references

## Visual interpretation

Figures are not decorative. The system can use them as evidence for:
- process steps
- system components
- spatial relationships
- labelled parts
- comparisons

Tables are evidence for:
- numerical relationships
- comparisons
- classifications

Equations are evidence for:
- quantitative relationships
- derivation steps
- variable definitions

## Fusion

Text-derived and visual-derived claims remain separately attributable.
They can be fused only after a conflict/consistency pass.

## Accuracy gates

If an image is unreadable, cropped, ambiguous or inconsistent with nearby text:
REVIEW — do not invent the missing information.

## Long-book architecture

The multimodal stage remains hierarchical:
page → section → chapter → book.
Only the relevant visual assets are attached to a unit's model request.

## Higher knowledge

The system may generate candidate extensions, but these remain separate from book-derived knowledge until external retrieval and verification are performed.
